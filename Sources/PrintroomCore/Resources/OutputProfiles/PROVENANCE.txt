ProPhotoRGB.icc is generated for Printroom as ICC v4.3 matrix/TRC RGB:
- D50 PCS white XYZ = (0.9642, 1, 0.8249).
- ROMM / ProPhoto primaries xy: R=(0.7347,0.2653), G=(0.1596,0.8404),
  B=(0.0366,0.0001). Colorants are solved against the D50 white.
- Encoded-to-linear TRC: E^1.8 for E >= 1/32; E/16 below 1/32.
- Parametric function 3: g=1.8, a=1, b=0, c=1/16, d=1/32.
- Profile ID is the ICC-prescribed MD5 with flags, intent and ID zeroed.
The system ROMM RGB profile was investigated and rejected: its parameter d is
1/512, inconsistent with the encoded-domain threshold. An independent dark-gray
analytic test caught the incorrect inverse response. No original input profile
was modified. Tests verify D50 colorants and the transfer toe independently.

Profile SHA-256 values are pinned in OutputColorProfile.profileSHA256. Original
embedded copyright and profile descriptions are retained. These are additional
local application resources, not replacements for the immutable ICC/ source.

The latter is Adobe's installed "Rec.2020 Gamma 2.4" display-referred profile.
Both are fixed, SHA-pinned ICC matrix/TRC profiles with D65 primaries adapted
into D50 PCS. Display P3 uses the sRGB transfer curve; Rec. 2020 uses Gamma 2.4
(SDR display-referred encoding, not PQ/HLG or camera OETF).
Apple's ITU-2020.icc was rejected: its ICC parametric curve describes the camera
OETF inverse, while CoreGraphics interprets it using a different display response
(midrange reference differences up to 0.102). The Adobe Gamma 2.4 profile avoids
this ambiguity; analytic and CoreGraphics references must both pass.
