# 0.3.65 工具栏卷名层级验收

日期：2026-09-28。卷名不再作为 PRINTROOM 字标下方的浅色副标题，而是工具栏独立标题；使用主文字颜色、15 点半粗字体，铅笔随卷名。长名称在可用宽度内中间截断，完整内容可通过悬停查看。主页仅显示品牌。

`bash scripts/editor-window-qa.sh --roll-name` 生成 1060 和 1360 点窗口、深浅两种外观的四张真实 AppKit 工具栏截图，目视检查品牌、卷名、铅笔及操作区在最小宽度下均可见，卷名与品牌分离。此变更只涉及工具栏布局与 QA 脚本，项目 schema、图像算法和导出行为不变。

`scripts/build-app.sh` 在本机图形环境完成 release 构建、资源核验、Apple M4 Metal 预览自检和签名验证，覆盖 `output/Printroom.app`；包内版本为 0.3.65。
