## 变更方法

已有授权内可以按验证证据调整工程默认；先写明原因和影响，再同步规范与测试。改变已确认的矩阵/公式/交互时不能自行伪装为优化。影响历史图像结果须更新算法版本并定义旧项目行为；只改变 JSON 结构则处理 schema 迁移。只修正系统展示表示、保持内部与导出数值不变时，使用独立展示策略版本使缓存失效，无需改动算法版本或项目 schema。新任务继续遵守用户最新明确要求。

工程默认以 Final 逐通道中位数作为代表色，保留其线性 Y，使用带边界的确定性多起点数值求解并检查真实整数参数。成功门槛是接近中性且亮度变化很小；无可接受解明确失败，避免把剪切或参数超限结果悄悄当作标定成功。
