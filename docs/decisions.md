## 变更方法

已有授权内可以按验证证据调整工程默认；先写明原因和影响，再同步规范与测试。改变已确认的矩阵/公式/交互时不能自行伪装为优化。影响历史图像结果须更新算法版本并定义旧项目行为；只改变 JSON 结构则处理 schema 迁移。新任务继续遵守用户最新明确要求。
