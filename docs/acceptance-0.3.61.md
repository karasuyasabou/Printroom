# 0.3.61 自动裁切指定画幅比例

用户要求增加预设、自定义比例，随后明确移除自动识别比例。设置面板默认3:2，支持常用比例、自定义宽高及交换宽高；非法输入不可开始，运行中锁定。指定比例参与整卷尺寸联合估计，继续使用既有位置/角度拟合与待检查流程。公式见pipeline.md，交互见interaction.md；不迁移旧裁框。

## 验证

- `scripts/test.sh --build-system native -c release --filter 'AutoCrop|CropTests'`：本机环境44项通过、2项真实胶卷可选测试跳过。日志 `/tmp/printroom-crop-tests-local.log`。
- 新增验证：只有一张照片时，独立估计会取740宽，指定3:2结合460高选回690宽；方形、自定义及竖幅比例；非法值拒绝；分析网格高度取整补偿；模型向后台传递指定比例。
- 既有裁切定位、整数几何、保存、撤销、取消、并发修改保护及裁切方向回归通过。
- 初轮构建中途因需求调整修改源文件而终止；重跑编译成功。沙盒内测试因Metal与临时目录访问限制失败，正常本机环境重跑通过，不将环境失败计为通过。
- `git diff --check`通过。
- `scripts/build-app.sh`在本机环境通过release构建、资源/Metal渲染验证和签名验证，交付`output/Printroom.app`，包内0.3.61（1），标识保持`studio.printroom.local.v3.3`。日志`/tmp/printroom-0.3.61-build-local.log`。首轮沙盒内资源验证无法创建Metal，未替换旧包；本机验证成功后才替换。

真实少片基胶卷的效果、设置面板实际窗口操作未执行；本轮未重跑15帧/76帧历史真实代理数据集。指定比例不会保证所有照片自动通过，比例选择错误、边缘弱或超出既有搜索带仍需人工检查。没有修改原始TIFF、ICC、LUT或用户胶卷。
