DSC07099（弱横边）和DSC07115（漏光片头）的新位置分别与旧实验相差9.804367和14.209251分析像素。旧实验并非这两张的标注真值：前者原已待检查，后者历史报告已指出置信度漏报。已逐张对照实际片框，新位置保留画幅且均为待检查。测试针对这两张采用独立粗中心范围(407,266)/(406,271)，每轴±3分析像素，并要求needsReview，不为全部样本放宽原位置容差。真实照片未建立逐像素人工标注，不能将该范围或自动通过比例当作准确率。

首轮及范围约束后的旧位置对照失败保留于`tests.log`、`tests-bounds.log`；它们不计通过。最终判定以`final-tests.log`为准。对照图为增强片基可见度的负片示意，不是Final调色验收。
