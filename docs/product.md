# 产品规范

状态：2026-09-07 工程基线。用户已确认定位、核心算法及复制/应用方案；实现尚未开始。

## 目标与范围

Printroom 是本地 macOS 原生负片调色与输出工具。输入为彩色负片扫描产生的 16-bit RGB 线性 TIFF；输出为经过 Kodak 2383 D65 外观处理的图像。无需 Photoshop，不引入胶片数据库、云同步或胶卷资产库。

一个文件夹就是一卷底片。打开其中一张 `.tif` / `.tiff`，读取同目录文件与旁存项目，不递归扫描子文件夹；原始文件不复制进项目。用户可以统一校准整卷，再对每张照片独立调色。

## 主要流程

1. 打开 TIFF，进入该卷并选中该照片。
2. 框选未曝光片基，以原始分辨率逐通道中位数计算卷级 Linear Gain 和校准偏移。
3. 选择卷级 Identity 或 LED Light Source 矩阵。
4. 调整当前照片的 Timing 与 RGB Contrast。
5. 复制当前照片参数，在 Filmstrip 多选目标，应用到整组选片；必要时撤销，再逐张微调。
6. 预览最终外观并导出；重新打开该卷后恢复卷级和帧级设置。

算法细节以 [pipeline.md](pipeline.md) 为准，交互细节以 [interaction.md](interaction.md) 为准。

## 参数作用范围

| 范围 | 设置 |
| --- | --- |
| 卷级 | 片基原始中位数、选区及来源、Linear Gain、自动校准偏移、矩阵、输入解释、LUT/profile 身份 |
| 帧级 | Master/R/G/B Timing、Master/R/G/B Contrast |
| 卷级导出偏好 | 输出 profile、嵌入 ICC、格式、位深、抖动、命名 |
| 会话 UI | 缩放、平移、多选集合、复制参数快照；当前照片与排序可保存为恢复偏好 |

片基校准与用户 Timing 分开保存。片基校准状态属于卷，而不是每张图片独立完成的工作。

## 分阶段范围

- M1：单张照片完整处理闭环、Metal 预览、默认 P3 输出；包括正确嵌入 ICC。
- M2：文件夹项目、自动保存、Filmstrip、复制/多选应用/撤销、缩略图缓存。
- M3：批量导出、额外输出 profile、性能与兼容性完善。

阶段完成条件见 [roadmap.md](roadmap.md)。第一版固定 470 CV pivot；可调 pivot 属于后续扩展。初期无需格式/位深选择器：只提供 16-bit TIFF，避免界面出现无效选项。
