# 阶段计划

状态日期：2026-09-07。用户已授权完成整卷调色可用版，不需逐阶段确认；本轮包含正确嵌入 ICC 的单张 16-bit TIFF 导出。批量导出、多输出色彩空间和最终性能优化明确移至下一轮。

## M0 — 工程准备：完成

代理规则、产品/算法/架构/交互/验收/决策文档、12 项资产清单与哈希、本地 Git 基线已建立。原始 TIFF/ICC/LUT 保持不变。

## M1 — 算法与单张闭环：已实现

- Swift 6 Package、原生 SwiftUI 应用包与重复构建脚本。
- Float32 CPU 参考、原始采样中位数、两种矩阵、校准、Timing、Contrast、LUT。
- 无隐式颜色转换的 UInt16 TIFF 读取；Metal 全阶段预览、缩放/平移与 RGB/CV 读数。
- 全尺寸分块计算，输出单张 16-bit P3 TIFF，嵌入原始 ICC。

算法、Metal、实际 TIFF 与集成测试已执行，结果见 [acceptance-0.1.0.md](acceptance-0.1.0.md)。输出当前采用无压缩 classic TIFF；不是尚未实现的 Deflate 输出。

## M2 — 整卷调色：已实现

目录发现、稳定 UUID、旁存项目、自动保存、Filmstrip、缩略图缓存、卷级校准、逐帧调色、复制快照、多选覆盖、Undo/Redo，以及保存冲突的设置副本/重新载入恢复入口。

已在 10 张实际样片副本上验证打开、片基框选、调色、全选应用、单次撤销和重开恢复。模型自动测试还覆盖 ⌘/Shift/⌘Shift 选择、不同帧参数、文件缺失与整卷移动。缺失文件可按原名重现后恢复；改名后的手动重新定位 UI 留待后续。

## 本轮从原 M3 提前完成的部分

单张完整尺寸 16-bit TIFF、正确 ICC 嵌入、源文件/重名保护、进度与取消、CPU/Metal 一致性及输出回读。基础分块和缓存用于可用性，不宣称完成最终性能优化。

## 下一轮

- 批量导出、队列与批量失败处理。
- Adobe RGB / sRGB / ProPhoto 等多输出 profile 的真实颜色转换。
- 最终性能优化、全分辨率预览策略和更完整设备兼容验证。
- 根据实际使用反馈补充手动重新定位、更多 TIFF 编码支持和缓存清理策略。

签名分发、商店、云同步、Intel、可调 pivot 不在本轮交付内。下一轮需有相应用户任务，代理不自行扩展。
