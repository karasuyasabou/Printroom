## M1 — 单张照片闭环

前提：用户明确启动应用开发。

顺序：

1. 创建最小可构建 app 与 CPU 测试核心，补充实测构建命令。
2. 原始 16-bit TIFF 解码、元信息诊断、片基原始像素采样。
3. Float32 CPU 全管线、矩阵/校准/Timing/Contrast、真实 LUT。
4. SwiftUI 单张编辑、阶段读数、Metal 预览，核对 CPU/GPU。
5. P3-D65 Gamma 2.6 的 16-bit TIFF 导出并嵌入 ICC；导出回读。

完成条件：验收计划 N01–N11、CPU/Metal、F01–F06/F08 已执行并记录；实际样片可完成闭环；色彩解释和 Cineon 衔接仍存在的限制明确报告；没有严重未解决的文件损坏/样本读取问题。ICC 嵌入是本阶段必需，不推迟到 M3。
