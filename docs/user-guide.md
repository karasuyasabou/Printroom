# 使用指南

## 打开胶卷

在主页选择“打开底片文件夹”。一个文件夹对应一卷，照片按文件名自然排序；最近打开的胶卷可以从主页继续编辑。

ARW 需要 Adobe DNG Converter。打开时会先准备整卷代理，完成后进入编辑器；加载失败时可以重试或返回主页。日常 RAW 编辑和放大查看使用代理，全尺寸处理在导出时进行。

点击顶部卷名旁的铅笔可重命名胶卷，只改变显示名称，不修改原片或文件夹名称。

## 校准与调色

1. 在“矩阵矫正”中选择 CMOS 和密度矩阵。矩阵与片基校准作用于整卷。
2. 点击“框选片基”，选择未曝光的片基区域。完成后恢复普通预览。
3. 调整当前照片的 Color Timing、RGB Contrast 和 Cineon Log LUT。Timing 可切换简易／RGB 模式，切换本身不改变照片参数。
4. 需要中性点校正时，按 `I` 开启吸管并点击照片。成功后调整 RGB Timing；无法得到合格结果时保留原参数。

“色罩分析”用于整卷基础调色。先完成有效画幅裁剪与片基校准，再开始分析；结果可以取消或应用到整卷。“保留已调色”默认不勾选，勾选后保留已经调整 Timing 或 Contrast 的照片。分析统一使用卷内第一张照片的 LUT，应用时同时更新目标照片的 LUT。

调色面板只编辑当前照片，即使选中了多张也一样。顶部“重置调色”只恢复当前帧调色。

## 选择与同步

- 普通点击缩略图切换当前照片；`⌘` 点击增减选择，`Shift` 点击选择连续范围，多选时保留当前照片。
- `⌘C` 复制当前照片的 Timing、Contrast 与 LUT；`⌘V` 将复制时的调色覆盖到所选照片。
- “同步…”可以分别勾选 Timing、Contrast、LUT 和裁剪，从当前照片应用到其余所选照片。每次打开默认全部不勾选。
- 一次批量操作可以用 `⌘Z` 整组撤销。同步裁剪保留目标照片各自的旋转与翻转。

## 裁剪与查看

按 `R` 进入裁剪，选择自由或固定比例，拖动边角调整范围，或在框内拖动位置。`Enter` 完成，`Esc` 取消当前草稿；裁剪中切换照片会保存上一张的裁剪并继续编辑下一张。

“自动裁剪”按指定画幅比例处理整卷，默认比例 3:2、每边内收 1%，默认不保留已有裁剪。需要保护现有裁框时勾选“保留已裁剪”。完成后若有待检查照片，会进入检查流程；用“确认并下一张”逐张确认。

取消勾选“裁剪预览”可查看完整画面，直方图仍按已保存的裁剪范围统计。此开关不会改变裁剪记录或导出设置。

预览工具栏提供四个旋转／翻转按钮和适应／100% 查看。RAW 的 100% 是代理放大。直方图可独立切换 Density／Final，也可以收起。

## 导出

从导出入口选择当前照片、所选照片或整卷，在设置窗口中选择目的地、文件名前缀、格式和色彩空间。

- TIFF 为 16-bit，ZIP 表示无损压缩；JPG 为 8-bit 有损格式。
- 色彩空间可选 sRGB IEC61966-2.1、Display P3、Adobe RGB (1998)、ProPhoto RGB 或 Rec. 2020，新卷默认 Display P3。
- “应用裁剪”默认勾选。关闭后导出完整画面并忽略裁剪微调角度，保留独立旋转和翻转。
- 文件名自动追加胶卷原编号，例如 `假日-02.tiff`；单独导出第二张仍使用 02。

确认导出才保存这卷的输出设置，取消不会改变原设置。遇到重名会询问如何处理；原片受到覆盖保护。导出期间可以继续调色，已经开始的任务使用提交时的参数。取消后保留已完成文件，结果窗口列出逐张状态。

## 保存与恢复

编辑设置自动保存在胶卷目录的 `.printroom.json` 中。移动胶卷时连同这个隐藏文件一起移动，才能保留调色和裁剪。

保存失败时编辑仍保留在内存中，可重试或通过文件菜单另存设置副本；也可恢复本卷的设置副本。缺失照片可在缩略图右键菜单中重新定位到卷内文件。

主页或文件菜单中的“管理缓存”可调整缓存容量与保留期限。缓存可重建，胶卷设置与原片不属于缓存。

## 常用快捷键

| 按键 | 操作 |
| --- | --- |
| `←` / `→` | 上一张／下一张 |
| `W` / `S` | 简易曝光增加／减少；RGB 模式 Master 增加／减少 |
| `Q` / `E` | 简易冷／暖；RGB 模式 Red 减少／增加 |
| `A` / `D` | 简易绿／洋红；RGB 模式 Green 减少／增加 |
| `Z` / `C` | RGB 模式 Blue 减少／增加 |
| `⌥` + 调色键 | 调整对应反差 |
| `I` | 开启／取消中性点吸管 |
| `R`、`Enter`、`Esc` | 进入／完成／取消裁剪 |
| 裁剪中 `Q` / `E` | 角度减少／增加 0.1° |
| `⌘C` / `⌘V` | 复制／粘贴调色 |
| `⌘Z` / `⌘⇧Z` | 撤销／重做 |
| `⌘⇧E` | 导出当前照片 |
| `⌘⇧/` | 打开完整快捷键帮助 |

在文本框中输入时保留文字编辑快捷键。浅色／深色可从“外观”菜单切换。
