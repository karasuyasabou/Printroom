## 打开胶卷

在主页选择“打开底片”。一个文件夹对应一卷，照片按文件名自然排序；最近打开的胶卷可以从主页继续编辑。

TIFF 支持无压缩、LZW 和 ZIP（Deflate）的 16-bit RGB 条带文件，包括 BigTIFF。

RAW（含 DNG）需要安装 [Adobe DNG Converter](https://helpx.adobe.com/camera-raw/using/adobe-dng-converter.html)，默认路径为 `/Applications/Adobe DNG Converter.app`。打开时会先准备整卷代理，完成后进入编辑器；加载失败时可以重试或返回主页。日常 RAW 编辑和放大查看使用代理，全尺寸处理在导出时进行。

新卷加载完成后自动弹出“命名胶卷”，取消时沿用文件夹名；已有项目重开不再提示。点击底部缩略图栏数量左侧、卷名旁的铅笔可重命名胶卷，只改变显示名称，不修改原片或文件夹名称。旁边的文件夹图标可在 Finder 中打开底片文件夹。

### RAW 格式

打开文件夹、重新定位原片和 CMOS 标定共用以下格式，扩展名不区分大小写，也可以与 TIFF 混合使用。

| 品牌／类型 | 扩展名 |
| --- | --- |
| Sony | ARW、SRF、SR2 |
| Canon | CRW、CR2、CR3 |
| Nikon | NEF、NRW |
| Fujifilm | RAF |
| Olympus／OM System | ORF |
| Panasonic | RW2、RAW |
| Pentax | PEF、PTX |
| Leica | RWL、RAW、DNG |
| Samsung | SRW |
| Hasselblad | 3FR、FFF |
| Phase One／Leaf | IIQ、MOS |
| Epson／Minolta／Mamiya | ERF、MRW、MEF |
| Kodak／Ricoh／Sigma／Casio | DCR、KDC、RDC、X3F、BAY |
| 通用 RAW／DNG | RAW、DNG |

这些格式已开放导入；具体机型和压缩模式还须由本机 Adobe DNG Converter 成功转换，并生成符合 Printroom 输入契约的线性 DNG。新机型可能需要更新转换器。转换或读取失败会显示错误，不切换其他解码流程；DNG 也统一经过 Adobe 准备，并非任意 DNG 都保证兼容。现有真实样片数值验收覆盖 Sony A7C II，其他机型的实际解码和色彩外观仍待验证。RAW 数值处理契约见 [算法与色彩管线](pipeline.md#raw-输入契约)。

## 校准与调色

矩阵与片基作用于整卷，Timing、Contrast 和 LUT 则逐张调整。即使选中了多张，面板也只编辑当前照片；顶部“重置调色”只恢复当前帧调色。

没有片基信息的卷先显示原图代理，“管线预览”固定为“原图”，暂不显示直方图或启用调色。可以先浏览、裁剪，也可以随时框选片基；成功后才进入处理预览。已有片基的卷重开时直接沿用，不提醒来源变化。每次成功框选记住新的片基颜色。

### 01 · 矩阵矫正

**CMOS 矩阵**在线性域工作，校正翻拍光源与相机传感器组合造成的三通道串扰，与底片无关。更换光源或相机，需要重新确认校正。可以在“管理…”中用 R、G、B 三张光源标定图建立自己的矩阵。

**密度矩阵**在密度域工作，可以把它理解为数字 mask。彩色负片的色罩原本服务于光化学印相，一般为 RA-4 相纸，并非 **Status M**。相纸的感光谱响应与 LED 窄带光源翻拍得到的通道响应不同，原有色罩在数字流程中存在差异。密度矩阵用于补偿这类光谱差异带来的色罩偏移。

关于光源校正和数字 mask 的思路，可以参考 [DiVERE](https://github.com/V7CN/DiVERE) 的说明。Printroom 中两种矩阵分属不同阶段，选择时需要分别考虑；内置密度矩阵为 （450nm, 535nm, 660nm）的LED光源对应矩阵，适合大部分胶卷。也可以录入自定义系数。

### 02 · Film Base 对齐

点击“框选片基”，在照片边缘拖出一块未曝光、干净且均匀的区域，避开齿孔、文字、灰尘和漏光。片基取样用这块区域建立调色基准，把不同通道的起点对齐。框选后会将这块区域对齐到 95 CV，作为调色起始点。

**片基取样不作为物理 Dmin。** Dmin 是特定曝光、冲洗和密度测量条件下的最小密度，包含片基与灰雾。这里框选的区域用于校准；对齐到 95 CV 是工作流程的参考位置，不表示设置了底片的绝对 Dmin。

### 03 · Color Timing

RGB Timing 对应 Cineon 配光流程，通过密度偏移模拟改变 R、G、B 的印光时间。Master 同时移动三个通道，RGB 分别控制通道偏移，用于调整亮度和颜色平衡。

**简易模式与 RGB 模式完全等效**。简易模式将其整理为曝光、色温、色调；RGB 模式直接操作 Master、Red、Green、Blue。选择顺手的一种即可，可随时切换，切换本身不改变照片参数。

有合适的灰色或白色物体时，按 `I` 开启中性点吸管并点击照片。成功后调整 RGB Timing；无法得到合格结果时保留原参数。

配光以 Cineon 的 **18% 中灰约 470 CV、漫反射白约 680 CV** 为参考；Printroom 的白点参考值为 **685 CV**。这些位置帮助确定密度与输出的对应关系，可在直方图中选择密度选项，查看密度分布直方图。

### 04 · RGB Contrast

Master 调整整体亮度反差，Red、Green、Blue 分别调整通道反差。调节围绕 685 CV 参考白点展开，直观感受就是修正了暗部偏色。

曝光和冲洗正常、矩阵矫正正确时，认为获得了 **“完美底片”**，理论上无需调节通道反差。如果冲洗出严重问题，直观感受就是白平衡调整完成后暗部发生偏色，可以通过通道反差修正一部分回来。不同通道反差会改变灰阶中的颜色关系，也可以用于美学调整。

### 05 · Cineon Log LUT

LUT 将调节后的负片密度转换为输出预览，决定正像的明暗曲线、色彩和印片外观。内置 Kodak 2383 与 Fujifilm 3513DI。

公式、常量和完整阶段定义以 [算法与色彩管线](pipeline.md) 为准。

## 色罩分析

色罩分析统计裁剪后的有效画面，为整卷求出共用的 RGB Timing，作为基础调色的起点。没有片基时点击会显示“请先框选片基”，可选择“框选片基”或“取消”；从此入口框选成功后自动打开分析确认弹窗。分析前确认有效画幅裁剪。

开始前可选择“自动曝光”（默认勾选）：先求整卷统一RGB，再按每张画面单独增加曝光，已足够亮的照片不再增加；夜景或刻意压暗的画面可能被提亮，建议留到逐张调整。

分析成功后可以取消或应用到整卷。“保留已调色”默认不勾选，勾选后保留已经调整 Timing 或 Contrast 的照片。分析统一使用卷内第一张照片的 LUT，应用时同时更新目标照片的 LUT，并将反差恢复为 1。

## 选择与同步

- 普通点击缩略图切换当前照片；`⌘` 点击增减选择，`Shift` 点击选择连续范围，多选时保留当前照片。
- `⌘C` 复制当前照片的 Timing、Contrast 与 LUT；`⌘V` 将复制时的调色覆盖到所选照片。
- “同步…”可以分别勾选 Color Timing、RGB Contrast、Cineon Log LUT 和裁剪，从当前照片应用到其余所选照片。每次打开默认全部不勾选。
- 一次批量操作可以用 `⌘Z` 整组撤销。同步裁剪保留目标照片各自的旋转与翻转。

## 裁剪与查看

### 手动裁剪

按 `R` 进入裁剪，从“长宽比”选择原始图像、常用比例或输入自定值；默认锁定比例，点击锁可解锁自由调整，“交换宽高”切换横竖。拖动边角调整范围，框内拖动位置，框外拖动旋转；也可用角度滑杆调整，双击滑杆归零。“重置”恢复完整图像、零角度和比例锁定。`Enter` 完成，`Esc` 取消当前草稿；裁剪中切换照片会保存上一张的裁剪并继续编辑下一张。

### 自动裁剪

“自动裁剪”按指定画幅比例处理整卷，默认比例 3:2、每边内收 1%，默认不保留已有裁剪。需要保护现有裁框时勾选“保留已裁剪”。完成后先检查裁框，尤其是首尾张、漏光或边缘不清楚的照片，排除齿孔与扫描边框后再进行色罩分析。若有待检查照片，会进入检查流程；用“确认并下一张”逐张确认。

同卷扫描文件的完整尺寸可以不同，自动裁剪按原片像素估计共同有效画幅，适用于有效画面像素尺寸一致、外围边框不同的扫描。边缘不明确或扫描范围不足的照片仍需逐张检查。

### 预览与直方图

取消勾选“裁剪预览”可查看完整画面，直方图仍按已保存的裁剪范围统计。此开关不会改变裁剪记录或导出设置。

预览工具栏提供四个旋转／翻转按钮。可用手势或滚轮缩放预览，拖动或双指滑动移动照片；移动到边界会停止，照片不会被移出显示区域。切换照片时自动恢复默认尺寸并居中，不提供“适应”按钮或双击复位；TIFF和RAW均使用代理预览。直方图可独立切换 Density／Final，也可以收起。

## 齿孔置白

点击顶部“自动裁剪”左侧的“齿孔置白”，开启后作用于整卷。先完成片基校准，并为需要保留齿孔的照片设置有效画幅裁框；没有裁框的照片保持原样。

识别阈值表示齿孔需要比片基亮多少，默认25%。降低阈值会包含更多框外亮区域，提高阈值会缩小范围；裁框内画面始终保留。开关和阈值自动保存，可以撤销。

取消“裁剪预览”即可查看完整底片上的效果。导出时取消“应用裁剪”以保留白色齿孔；应用裁剪后齿孔随框外区域一起裁掉。

## 导出

顶部“导出”提供所选照片和整卷，单选时即可导出当前照片；也可通过文件菜单或 `⌘⇧E` 直接导出当前照片。在设置窗口中选择目的地、文件名前缀、格式和色彩空间。

- TIFF 为 16-bit，ZIP 表示无损压缩；JPG 为 8-bit 有损格式。
- 色彩空间可选 sRGB IEC61966-2.1、Display P3、Adobe RGB (1998)、ProPhoto RGB 或 Rec. 2020，新卷默认 Display P3。
- “应用裁剪”默认勾选。关闭后导出完整画面并忽略裁剪微调角度，保留独立旋转和翻转。
- 文件名自动追加胶卷原编号，例如 `假日-02.tiff`；单独导出第二张仍使用 02。

确认导出才保存这卷的输出设置，取消不会改变原设置。遇到重名会询问如何处理；原片受到覆盖保护。导出使用提交时的参数。进度显示在设置窗口底部，可点击“取消导出”；取消后保留已完成文件。结束后原位显示成功、失败或取消状态，点击“关闭”退出。

## 保存与恢复

编辑设置自动保存在胶卷目录的 `.printroom.json` 中。移动胶卷时连同这个隐藏文件一起移动，才能保留调色和裁剪。

保存失败时编辑仍保留在内存中，可通过文件菜单“保存胶卷设置”重试或另存设置副本；也可恢复本卷的设置副本。缺失照片可在缩略图右键菜单中重新定位到卷内文件。

主页或文件菜单中的“管理缓存”可调整缓存容量与保留期限。缓存可重建，胶卷设置与原片不属于缓存。

## 常用快捷键

| 按键 | 操作 |
| --- | --- |
| `W` / `S` | 简易曝光增加／减少；RGB 模式 Master 增加／减少 |
| `Q` / `E` | 简易冷／暖；RGB 模式 Red 减少／增加 |
| `A` / `D` | 简易绿／洋红；RGB 模式 Green 减少／增加 |
| `Z` / `C` | RGB 模式 Blue 减少／增加 |
| `⌥` + 调色键 | 调整对应反差 |

| `⌘F` | 水平翻转 |

裁剪快捷键：

| 按键 | 操作 |
| --- | --- |
| `R` | 进入裁剪 |
| `W` / `S` / `A` / `D` | 裁框向上／下／左／右移动 |

在文本框中输入时保留文字编辑快捷键。浅色／深色可从 PRINTROOM 旁的太阳／月亮开关切换。

## 理解密度与配光

Printroom 以**密度操作为主**完成负片去色罩。线性域处理翻拍设备记录的通道数值，密度域处理数字 mask、配光和反差，最后由 LUT 将负片密度转换为可观看的正像。

```text
线性 RGB → CMOS 矩阵与片基增益 → 转为密度
        → 密度矩阵 → 片基对齐与 RGB Timing → RGB Contrast
        → Cineon Log LUT → 显示与导出
```

### Cineon CV、底片密度与 EV

Cineon 用 CV（Code Value，码值）表示密度。**1 CV 对应 0.002 密度变化**，因此增加 50 CV 就是增加 0.1 密度。

以 Kodak VISION3 250D 5207 为例（曲线来源：[Kodak 5207 技术资料](https://www.kodak.com/content/products-brochures/motion-picture/KODAK-VISION3-250D-5207-7207-technical-information.pdf)）：

<p align="center">
  <img src="images/kodak-5207-exposure-curve.png" width="300" alt="Kodak 5207 官方感光特性曲线：横轴为拍摄曝光档数与对数曝光量，纵轴为 Status M 密度，分别绘出 R、G、B 三通道">
</p>

横轴是拍摄曝光档数。纵轴是冲洗后的底片密度。按图粗读，线性段每档大约增加 0.16 密度，即每档约 80 CV。

#### Cineon 的黑、灰、白参考点

| 参考点 | 定义 | CV |
| --- | --- | ---: |
| 参考黑 | 黑位基准 | 95 |
| 18% 中灰 | 正常曝光的中性灰参考，用于配光 | 470 |
| 90% 漫反射白 | 正常曝光的白色漫反射物体，不含镜面高光 | 685 |

黑位设在 95 CV，白位设在 685 CV，分别在其下方和上方留出数值空间。685 CV 是漫反射白的参考位置，高于它仍可以记录更亮的高光；470 CV 则用于判断中灰的配光位置。

公式、常量和完整阶段定义以 [算法与色彩管线](pipeline.md) 为准。
