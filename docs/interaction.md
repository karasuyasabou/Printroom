# 编辑与复制/应用交互

状态：2026-09-08，0.3.2。复制快照、覆盖应用、整组撤销，以及多选保持当前编辑帧、原片裁剪同步和单行裁剪栏均按用户确认执行；其余细节为工程默认。

## 布局与单张编辑

主预览在左、调色面板在右，Filmstrip 位于底部。调色面板按编号依次显示：01 Film Base 对齐、02 密度矩阵、03 Color Timing、04 RGB Contrast。Film Base 对齐与密度矩阵为独立分组，均作用于整卷；片基来源复核提醒留在对齐分组。输出选项在导出对话框中显示。主预览支持缩放、平移、片基矩形选区、阶段切换与中性点吸管。

双指滑动按 macOS 滚动事件的方向平移照片，遵循系统“自然滚动”设置，不额外反转水平或垂直位移。

预览视口由页面剩余空间决定；缩放和平移只改变视口内的图像变换，不参与页面尺寸计算。SwiftUI 容器、AppKit Canvas 及绘图上下文都裁切到此边界，图像与选区不得覆盖工具栏、右侧面板或 Filmstrip。片基选区同时受图像与视口交集约束。

鼠标按下、滚轮、捏合和取样只响应视口内位置；拖出时暂停平移/框选，重入不累计窗外平移量，窗外松开取消提交。窗口改变尺寸时取消进行中的拖动，避免混用两套坐标。取样仍按完整 imageRect 逆映射到 orientation 校正后的原始尺寸，不用可见裁切矩形拉伸映射。“适应窗口”、双击和切帧统一清除平移与临时选区并恢复居中 fit。TIFF 方向校正在导入阶段完成，用户追加方向见下方方向操作。

面板始终编辑当前主预览帧 `activeFrameID`，即使选中多张，拖动控件也只修改当前帧。批量修改通过明确的“应用”按钮进行。当前文件名统一显示在预览工具栏，Filmstrip 突出当前帧；调色面板不再重复“当前照片”或“正在编辑”文字。

## 当前帧、选择集合与锚点

维护三个独立状态：`activeFrameID`、`selectedFrameIDs`、`selectionAnchorID`，均使用稳定帧 ID。非空选择中 active 必须是集合成员。当前帧突出边框，其他选中帧使用选择背景；两种状态不能只有不可辨认的细微色差。

| 操作 | 行为 |
| --- | --- |
| 普通点击 | 集合替换为该帧，该帧成为 active 和 anchor |
| ⌘ 点击未选中帧 | 加入目标集合，保持 active 和 anchor |
| ⌘ 点击已选中非当前帧 | 从目标集合移除，保持 active 和 anchor |
| ⌘ 点击当前帧 | 不改变选择；active 始终保持选中 |
| Shift 点击 | 从普通点击确定的 anchor 到目标（含端点）替换连续目标集合，保持 active 和 anchor，并确保 active 仍在集合中；无 anchor 则等同普通点击 |
| ⌘Shift 点击 | 将 anchor 至目标区间加入原集合，保持 active 和 anchor |
| ⌘A（无文本输入焦点） | 全选当前卷可用帧，保留 active；无 active 则取第一张 |

⌘/Shift/⌘Shift 只修改批量目标，不切换主预览，不取消裁剪草稿，也不复位缩放或平移；普通点击才切换 active 并重新确定 anchor。没有 active 的初始状态以首个有效点击建立 active 和 anchor。排序变化按稳定 ID 保留选择，后续 Shift 范围以新顺序为准；外部源变化导致 active 不再可用时才按可用集合修复选择。缺失/不可用文件保留条目但不可加入选择；若已选文件在应用前丢失，应用失败且不修改任何帧。

## 复制参数

⌘C 复制当前帧参数，⌘V 应用到所选照片，替代原 ⌘⇧C/⌘⇧V。由编辑器窗口路由；文本编辑、弹窗及失焦时保留系统行为，长按不重复操作。

“复制参数”从 active 帧生成不可变快照，包含四个整数 Timing、四个 Contrast，以及快照格式版本、算法版本、固定 pivot 标识、来源帧 ID 与显示文件名。

不复制：片基选区、base、Linear Gain、自动偏移、矩阵、LUT、输入解释、方向、裁剪、输出 profile、选择状态、缩放与缓存。

无 active 时按钮禁用；多个选中项不影响来源。快照一旦复制，不随来源照片后续修改而变化。界面显示“已复制：文件名”。快照只在当前卷会话内保存在内存，不写系统剪贴板，不写项目；切换卷或退出时清空，避免无意跨卷应用。来源帧之后丢失不影响已经保存的快照值。

## 应用

按钮有快照且选择非空才启用。显示“应用到 N 张”，N 包含集合内全部目标；只选一张时应用到该张。点击时捕获快照和目标 ID 列表，不因异步渲染或后续选择改变目标。

1. 校验快照格式/算法兼容性、每个目标可用性与参数范围。
2. 整组覆盖目标帧的 Timing 和 Contrast，不加算、不乘算、不修改卷级校准。
3. 在一个事务中更新模型，一次性登记 undo，标记项目待保存并更新受影响缩略图。
4. 显示“已应用到 N 张”；不会改变当前选择或 active。

任一目标无效则整组失败，不产生部分应用。若所有目标原本已相同，则提示“所选照片参数已相同”，不增加无意义撤销记录。来源照片也在目标中时按同一规则覆盖。普通批量应用不弹确认对话框。

## 撤销与保存

一次应用对应一次 UndoManager 操作，每帧分别保存应用前参数；⌘Z 一次恢复全部，Redo 一次重新应用。手动滑块从按下到松开作为一组撤销，数值提交一次为一组。

重新采样或切换矩阵是一次卷级事务与撤销，恢复相关 base/gain/offset/matrix；保持帧级用户参数。撤销栈仅会话内有效，重开项目不恢复历史。复制不进入撤销栈。

应用后立即安排自动保存；保存失败保留内存参数和撤销能力，显示未保存状态与重试入口，不能错误提示“已保存”。保存策略见 [architecture.md](architecture.md)。

## Timing 快捷键

| 按键 | 操作 |
| --- | --- |
| Q / E | Red −1 / +1 CV |
| A / D | Green −1 / +1 CV |
| Z / C | Blue −1 / +1 CV |
| W / S | Master +1 / −1 CV |
| [ / ]（【 / 】） | 当前照片左旋转 / 右旋转 90° |
| ⌘F | 当前画面水平翻转 |
| ← / → | 上一张 / 下一张可用照片 |
| I | 开启 / 取消中性点吸管；长按不反复切换 |

窗口内无文本输入焦点、无弹窗、未进入裁剪且没有 Command/Control 修饰时生效。点击 Filmstrip 先提交数值输入并结束文本焦点，随后可以直接调色；不再存在 Filmstrip 专属调色焦点模式。无 Option 调 Timing，有 Option 调对应 Contrast。⌘A 在无文本焦点时全选照片，在文本内保留全选文字；⌘C/⌘V 在无文本焦点时复制/应用参数，在文本内保留文字复制/粘贴；⌘Z 和文本输入法不被调色字母键截获。单击每次 1 CV，Shift + 快捷键单击每次 10 CV。按住约 0.4 秒后由应用计时，以固定 50 CV/秒连续调节，不渐进加速，Shift 不放大连续速率；不依赖 macOS 键盘重复设置。松手立即停止；换键重新计时，切帧、失焦或弹窗时终止。一次按住到松开对应一次撤销/重做，到达控件范围即停止变化且不追加空撤销。滑杆、输入框及快捷键共享 [pipeline.md §7](pipeline.md#7-timing-与-rgb-contrast) 的范围。

## Filmstrip 与卷级状态

缩略图显示文件名、序号、当前/选中状态，以及帧级参数是否偏离默认值。校准状态来自整卷，可显示统一卷级标记；不能因为某帧 Timing 不为零就标记为未校准。

卷级校准改变会影响全卷预览与缓存，无需逐张“应用校准”。未校准时用户可继续编辑和导出；调色面板不再显示常规校准数值与说明，只有片基来源变化需复核时显示操作提醒。首次打开只选中被打开的 TIFF；重开卷可恢复上次 active，明确打开另一张 TIFF 时以该文件为准。

## 0.2.0 新增操作

预览工具栏及“方向”菜单提供顺/逆时针 90°、当前显示方向水平/垂直翻转、重置。每次只改变 active 帧的方向，形成一次 Undo/Redo，重开恢复。组合与原始坐标见 [pipeline.md §10](pipeline.md#10-020-用户方向与原始坐标)。复制/应用仍然只含 Timing 和 Contrast，方向、输出设置不混入快照。

“1:1”/⌘1 使一个原片像素对应一个物理显示像素（Retina 使用 backing scale），居中读取当前可见原始区域；继续平移按需更新，读取中显示状态。适应窗口/双击/切帧/改方向复位视口。高倍缩放用原始区域覆盖低分辨率底图，像素不做精度降级；整图直方图保持独立。

整图预览直方图位于预览视口右上角，以半透明深色浮层显示，可选 RGB、R、G、B。图表随窗口定位、不参与照片缩放；详细端点、域外与非有限统计从信息按钮按需展开。片基框选提示放在预览底部，避免与直方图重叠。

Color Timing 与 RGB Contrast 共用横向滑杆样式，从上到下以白、红、绿、蓝表示 Master/R/G/B，不显示通道文字。右侧数值可输入；Timing 不显示 CV 后缀。通道名称保留在悬停提示和辅助功能标签中；键盘步长与连续调节遵循上文 Timing 快捷键规范，参数范围见 pipeline.md，整组撤销语义保持。移除 BASE/GAIN/OFFSET、校准成功说明、快捷键小字、Pivot 行及管线说明。

当前照片、所选照片和整卷导出均在对应保存/目录对话框内显示四种输出 ICC、无压缩/Deflate 和 16-bit TIFF 格式。打开时载入本卷上次选项；取消不保存草稿，确认导出才保存并固定任务快照，不影响预览。

导出菜单提供当前照片、选中集合、整卷三种入口。批量选择目录，当前照片可指定文件名。任务开始时固定目标及设置，此后可以调色、改变选择、Undo/Redo、旋转，不影响正在执行的任务；切换胶卷和退出须先完成或取消导出。进度显示照片及总体数量；结果逐张列出成功路径、失败原因、取消或未开始，用户可在 Finder 显示成功文件。单张失败继续其他帧，取消保留已完成并清理未完成临时文件。

缺失帧保留在 Filmstrip，右键“重新定位此照片”选择卷内 TIFF。手动重连保留稳定 ID、调色和方向；目标已被其他编辑帧占用时拒绝合并，原路径仍可读时拒绝误重连。片基来源重连后提示复核。顶部胶卷管理菜单可主动清理可再生缩略图缓存；导出菜单可再次查看上次结果。

旋转、翻转及左右切图在编辑器窗口生效，包含预览、滑杆和Filmstrip焦点；文本输入、输入法组合及弹窗期间不拦截。四个方向键不再调节滑杆；↑/↓无调色动作。左右切图采用单选、跳过缺失帧，首尾停止、不循环；无当前帧时选择第一张可用照片。旋转与翻转沿用原有单次撤销和帧级保存。


连续调参时主预览持续显示按顺序完成的参数快照，停止输入后收敛到最后参数；切图、阶段、校准、方向变化不显示旧上下文的结果。整图直方图在最新预览稳定后更新；高频输入期间保持上一份完整统计，不清空、不显示转圈或更新提示，完成后直接替换。切帧、阶段或校准/几何上下文变化清除不匹配统计。保存、撤销、调色步长与范围不变。


## 0.3.1 裁剪与同步

预览工具栏在“方向”旁提供“裁剪”，R 进入。裁剪栏为单行：比例菜单、横竖切换、角度减/滑杆/加、两位小数角度输入、重置、取消、同步与完成。比例提供 3:2、4:3、1:1、7:6；滑杆范围 ±10°，按钮每次 0.1°，输入精确到 0.01°，双击滑杆归零。栏内不显示输出尺寸或常驻说明，名称与帮助通过悬停和辅助功能保留。没有画线自动拉直工具。重置裁剪显示“全图”，属于草稿，完成时才清除帧裁剪。

编辑时展示全图，框外暗色遮罩、网格、四角四边把手；框内拖动移动，边角拖动保持当前比例。照片围绕全图中心旋转，框始终水平；显示角度与横竖按当前照片方向呈现，保存时转换为原片坐标。约束与自动收边由 pipeline.md §14 定义。Enter/完成只修改当前帧；Esc/取消恢复进入前裁剪，整次提交一次 Undo。R、Enter、Esc 仅无文本输入/弹窗时由编辑器处理；角度输入 Enter 先提交输入值。编辑中不触发左右切图、方向变换、1:1 或导出；Filmstrip 普通点击切换当前帧时取消未提交裁剪，⌘/Shift/⌘Shift 扩选保持当前照片和草稿。按住调色键的动作在进入裁剪时结束。

同步入口仅在裁剪栏内，显示“同步 N 张”；上方预览工具栏不另设同步按钮或菜单。可先多选再进入裁剪，也可边裁剪边扩选，拖动本身只更新当前草稿。点击同步时捕获原片坐标下的草稿和全部所选目标，按每个目标 TIFF 方向校正后的原始尺寸适配范围，用户方向不参与裁剪拟合。同尺寸照片得到相同原片裁剪值，保留各自 D4，因而旋转照片的最终显示比例可以互为横竖。同步包括细旋转角度，保留目标方向、Timing、Contrast 与卷级校准。预校验全部目标可用且可读取元信息，失败整组不变；一次 Undo 恢复每帧各自原裁剪。全图状态也可同步以清除所选裁剪。相同结果不增加撤销记录。

草稿不写项目或导出快照。完成后自动保存并适应裁后画面，主预览、Filmstrip、直方图、1:1 与导出使用已提交裁剪。缩略图的编辑状态包含裁剪。片基取样的全图恢复规则见 pipeline.md §14。已有“复制参数/应用参数”继续仅包含 Timing 和 Contrast。


## 0.3.2 编辑器精简与中性点

顶部“重置参数”位于“复制参数”左侧，仅重置当前帧 Timing/Contrast，一次撤销，无确认弹窗；右侧调色面板不再重复重置按钮。普通点击预览不取样，原像素读数功能及整条读数栏移除。底部“已保存”常驻栏移除；保存失败才显示顶部重试入口，导出期间顶部临时行显示进度与取消，导出结果继续按需查看。1:1 状态并入原按钮，区域读取失败有可见错误提示。

Color Timing 标题右侧提供中性点吸管。点击或按 I 启用，预览内指针变吸管，尖端为取样点，点一次完成并退出；Esc/I/再次点击按钮取消。I 沿用窗口快捷键的文本输入、弹窗与失焦保护，长按不反复切换。片基框选状态在预览内显示十字指针；工具切换、取样完成和取消立即更新鼠标形状，无需移动。移出预览后由所在控件使用正常指针。片基框选与裁剪互斥，正式预览未准备好时禁用精确取样。0.3.3 起取样以原片邻域的 Final 中位数为中性目标，尽量保持最终亮度；目标和数值容差以 pipeline.md §15 为准。帮助文字标明 Final 中性，不随当前诊断阶段改变目标。只改变当前帧 RGB Timing，整次操作一次撤销并沿用保存、缩略图与复制语义。取样等待中切帧、调参、切阶段、改校准/几何或取消时丢弃结果；无效取样、无法收敛或整数精度不足时明确失败，已有参数保留。求解在后台进行，等待期间取消或继续调色会丢弃结果。

Option + Q/E、A/D、Z/C、W/S 按同一正负方向调整 RGB/Master Contrast，每次单击 0.01；Option+Shift 也为 0.01。长按延迟与原 Timing 相同，之后固定每秒 0.20，无 Shift 加速；一次按下至松开一组撤销。按实体键码路由，避免 Option 死键产生的特殊字符干扰；修饰键变化、松键、失焦、弹窗或切帧均停止。

所有密度阶段 D0–D3 直方图显示 0…1024 CV，95、470、685 位置使用轻淡参考线与数字，不增加黑点/灰点/白点说明文字；其余阶段仍显示 0…1。统计范围与 bins 不改变，转换规则见 pipeline.md §12。构建 3 起直方图采用整图均匀取样（小图精确），与对应正式画面同时替换；详情注明取样数与估计比例。

切帧立即显示匹配该帧当前设置的已缓存主预览，未命中则使用匹配的 Final 缩略图；正式预览完成后原位替换，无淡入淡出、无中央加载浮层。没有任何占位图且等待超过 600ms 时才显示角落小提示。占位图只用于显示，不开启片基/吸管/裁剪/1:1 等精确操作。缓存身份、容量及失效规则见 architecture.md。
