# 编辑交互

当前版本0.3.69。本文规定当前有效的界面与编辑语义；数值见[pipeline.md](pipeline.md)，保存与模块见[architecture.md](architecture.md)。面向使用者的简短说明见[使用指南](user-guide.md)。

## 布局

主预览在左、调色面板在右，Filmstrip 位于底部。调色面板按编号依次显示：01 矩阵矫正（上 CMOS 矩阵、下密度矩阵）、02 Film Base 对齐、03 Color Timing、04 RGB Contrast、05 Cineon Log LUT。Film Base 对齐与矩阵矫正为独立分组，均作用于整卷；片基对齐分组仅保留框选入口，不显示来源复核提醒。输出选项在导出对话框中显示。主预览支持缩放、平移、片基矩形选区、阶段切换与中性点吸管。

双指滑动按 macOS 滚动事件的方向平移照片，遵循系统“自然滚动”设置，不额外反转水平或垂直位移。鼠标拖动与双指平移共用位置边界：横纵分别判断，照片该轴小于视口时完整保留在视口内，大于视口时两端不得移入视口而露出照片外空白。缩放、窗口尺寸和显示尺寸变化后立即重新约束位置；到边缘停止，反向移动立即响应，不累积越界位移。裁剪模式使用固定±10°外包络约束小图，放大时沿用未旋转图像边界并收紧极端角落的移动范围，保证所有允许角度下实际照片与视口仍有交集；该轴原图能放下而外包络放不下时保持居中，调整角度不移动视口。

预览视口由页面剩余空间决定；缩放和平移只改变视口内的图像变换，不参与页面尺寸计算。SwiftUI 容器、AppKit Canvas 及绘图上下文都裁剪到此边界，图像与选区不得覆盖工具栏、右侧面板或 Filmstrip。片基选区同时受图像与视口交集约束。

鼠标按下、滚轮、捏合和取样只响应视口内位置；拖出时暂停平移/框选，重入不累计窗外平移量，窗外松开取消提交。窗口改变尺寸时取消进行中的拖动，避免混用两套坐标。取样仍按完整 imageRect 逆映射到 orientation 校正后的原始尺寸，不用可见裁剪矩形拉伸映射。首次显示、切帧、方向变化和裁剪显示几何切换时清除平移与临时选区并恢复默认尺寸、居中；不提供手动适应或双击复位。TIFF 方向校正在导入阶段完成，用户追加方向见预览工具栏中的方向操作。

面板始终编辑当前主预览帧 `activeFrameID`，即使选中多张，拖动控件也只修改当前帧。批量修改通过明确的“应用”按钮进行。卷名显示在 Filmstrip 数量左侧，Filmstrip 突出当前帧；调色面板不再重复“当前照片”或“正在编辑”文字。

## 当前帧、选择集合与锚点

维护三个独立状态：`activeFrameID`、`selectedFrameIDs`、`selectionAnchorID`，均使用稳定帧 ID。非空选择中 active 必须是集合成员。当前帧突出边框，其他选中帧使用选择背景；两种状态不能只有不可辨认的细微色差。

| 操作 | 行为 |
| --- | --- |
| 普通点击 | 集合替换为该帧，该帧成为 active 和 anchor |
| ⌘ 点击未选中帧 | 加入目标集合，保持 active 和 anchor |
| ⌘ 点击已选中非当前帧 | 从目标集合移除，保持 active 和 anchor |
| ⌘ 点击当前帧 | 不改变选择；active 始终保持选中 |
| Shift 点击 | 从普通点击确定的 anchor 到目标（含端点）替换连续目标集合，保持 active 和 anchor，并确保 active 仍在集合中；无 anchor 则等同普通点击 |
| ⌘Shift 点击 | 将 anchor 至目标区间加入原集合，保持 active 和 anchor |
| ⌘A（无文本输入焦点） | 全选当前卷可用帧，保留 active；无 active 则取第一张 |

⌘/Shift/⌘Shift 只修改批量目标，不切换主预览，不取消裁剪草稿，也不复位缩放或平移；普通点击才切换 active 并重新确定 anchor。没有 active 的初始状态以首个有效点击建立 active 和 anchor。排序变化按稳定 ID 保留选择，后续 Shift 范围以新顺序为准；外部源变化导致 active 不再可用时才按可用集合修复选择。缺失/不可用文件保留条目但不可加入选择；若已选文件在应用前丢失，应用失败且不修改任何帧。

## 复制与同步

⌘C复制当前照片的Timing、Contrast和Cineon Log LUT为不可变快照；之后修改来源不改变该快照。⌘V覆盖全部所选目标，不累加。快照仅当前卷会话有效，切卷或退出清空；来源丢失不使已复制值失效。方向、裁剪和卷级校准不进入调色快照。

Filmstrip上方“同步…”在多选时启用，从当前照片已提交设置覆盖其余所选照片，目标数排除当前帧。提供Color Timing、RGB Contrast、Cineon Log LUT、裁剪四项，前三项名称和大小写与外部面板标题一致。每次打开全部不勾选，至少选择一项才可应用。切换当前帧或选择集合关闭浮层。裁剪需先完成再同步；同步保留目标各自方向和未勾选内容。

浮层保留“同步”标题和来源文件名，目标数量仅在“应用到 N 张”按钮中显示。

全体目标先校验，失败整组不变；成功一次事务、一次撤销，保存并更新目标缩略图。完全相同的结果不增加撤销。取消或关闭浮层不修改项目，来源帧与选择集合保持。

## 撤销与保存

单次滑杆拖动、数值提交、连续长按或批量命令分别组成一组撤销。矩阵应用与片基重新对齐共同提交和撤销，逐帧Timing/Contrast保持。复制本身不产生撤销，重开项目不恢复撤销历史。

普通调参防抖保存，操作结束和批量命令安排立即保存；保存失败保留内存参数、dirty与撤销，显示原生错误提示，可通过文件菜单“保存胶卷设置”重试。切卷、返回主页和退出先检查保存；主窗口关闭在保存成功后退出，导出进行中或保存失败时保留窗口。关闭辅助窗口不退出。持久化规则见[architecture.md](architecture.md)。


## 调色快捷键

下表为RGB Timing模式；简易模式的路由见下一节。

| 按键 | 操作 |
| --- | --- |
| Q / E | Red −1 / +1 CV |
| A / D | Green −1 / +1 CV |
| Z / C | Blue −1 / +1 CV |
| W / S | Master +1 / −1 CV |
| [ / ]（【 / 】） | 当前照片左旋转 / 右旋转 90° |
| ⌘F | 当前画面水平翻转 |
| ← / → | 上一张 / 下一张可用照片 |
| I | 开启 / 取消中性点吸管；长按不反复切换 |

窗口内无文本输入焦点、无弹窗、未进入裁剪且没有 Command/Control 修饰时生效。点击 Filmstrip 先提交数值输入并结束文本焦点，随后可以直接调色；不再存在 Filmstrip 专属调色焦点模式。无 Option 调 Timing，有 Option 调对应 Contrast。⌘A 在无文本焦点时全选照片，在文本内保留全选文字；⌘C/⌘V 在无文本焦点时复制/应用参数，在文本内保留文字复制/粘贴；⌘Z 和文本输入法不被调色字母键截获。单击每次 1 CV，Shift + 快捷键单击每次 10 CV。按住约 0.4 秒后由应用计时，以固定 25 CV/秒连续调节，不渐进加速，Shift 不放大连续速率；不依赖 macOS 键盘重复设置。松手立即停止；换键重新计时，切帧、失焦或弹窗时终止。一次按住到松开对应一次撤销/重做，到达控件范围即停止变化且不追加空撤销。滑杆、输入框及快捷键共享 [pipeline.md §7](pipeline.md#7-timing-与-rgb-contrast) 的范围。

## 简易 / RGB Timing

Timing标题行提供“简易 / RGB”分段切换，吸管仍在最右侧。首次默认简易，本机偏好记住选择；切图、切卷、重启保持，复制/同步/撤销不改变模式。切换停止在途长按，参数和画面不变，不单独产生撤销。

简易模式显示曝光、色温、色调及可编辑数值；色温左冷右暖、色调左绿右洋红，悬停和辅助功能提供方向/按键。三条滑杆后保留一行空白，Contrast位置与四条RGB模式相同。拖动一次为一组撤销，双击复位遵守pipeline.md的整数格点/范围约束。

全部调色滑杆支持双击复位当前一项：简易曝光/色温/色调与RGB Timing的Master/R/G/B目标为0，Contrast的Master/R/G/B恢复无调整值1.00。仅滑杆区域响应，数值输入框保持原生编辑行为；参数、数值与滑块位置同步刷新，沿用调参撤销流程。裁剪角度滑杆继续双击归零。

仅Timing快捷键随模式变化：简易W/S曝光增加/减少，Q/E偏冷/偏暖，A/D偏绿/偏洋红，Z/C无作用；RGB模式保留原路由。简易单击1、Shift单击10，0.4秒后每秒25个轴单位，无Shift长按加速。所有Option反差快捷键在两种模式均保持原含义、步长、长按速率和可用条件，包括Option+Z/C。文本、弹窗、裁剪及失焦保护沿用原有规则。

快捷键帮助依次展示简易Timing、RGB Timing、裁剪、Contrast和照片与预览。裁剪单独分组，列出R、W/S/A/D及Q/E；简易Timing不列无操作的Z/C。旋转只写[ / ]，不补充中文括号说明。帮助表省略左右切图、Enter/Esc、多选、全选、复制粘贴、撤销重做、保存及系统窗口操作等常见快捷键；保留旋转、水平翻转、中性点与导出。此处只精简展示，快捷键行为保持。

简易模式数值显示为四舍五入的整数，底层坐标与继承分数余量保留；仅查看和切换模式不修改参数。LUT逐帧可选Fujifilm 3513DI或Kodak 2383，默认Kodak 2383；顶部重置同时恢复Timing、Contrast和LUT。


## Filmstrip 与卷级状态

Filmstrip 可用帧的右键菜单提供“水平翻转x张底片”“垂直翻转x张底片”“顺时针旋转x张底片”“逆时针旋转x张底片”，x 为当前选中集合数量（包含当前帧）。右键不改变选择；操作作用于所选集合，每帧基于自己的当前画面翻转或旋转 90°，保留原片裁剪与调色。整组校验、一次撤销/重做、自动保存并刷新受影响缩略图；缺失目标则全部不改。裁剪编辑、胶卷加载或无选择时禁用。预览工具栏与快捷键仍只改变当前帧。

缩略图显示文件名、序号、当前/选中状态；不再显示帧级参数偏离默认值的黄点。校准状态来自整卷，可显示统一卷级标记；不能因为某帧 Timing 不为零就标记为未校准。

卷级校准改变会影响全卷预览与缓存，无需逐张“应用校准”。未校准时主预览与缩略图显示原图代理，管线预览固定为不可选的“原图”；隐藏直方图，禁用Color Timing、RGB Contrast、LUT、中性点吸管及调色快捷键，裁剪与方向继续可用。成功首次框选后恢复处理界面并默认输出；取消或失败保留原图，不自动色罩分析。导出规则保持。调色面板不显示常规校准数值或来源复核提醒；已存片基继续使用，每次成功框选更新卷级采样快照，失败保留旧值。新卷选择首个可用帧；重开卷恢复上次当前帧。

## 双矩阵管理

“01 矩阵矫正 · 整卷”标题右侧提供“管理…”，点击浮层选择 CMOS 矩阵或密度矩阵，再打开对应管理弹窗。主面板上下两行分别为 CMOS、密度矩阵，每行左侧标签、右侧选择器。新建胶卷默认 CMOS 为 Sony A7C II、密度为 LED Light Source；两侧仍可选 Identity，已有胶卷读取保存的选择。内置项带锁，只读、可复制，不能编辑或删除。

管理弹窗左侧为内置和本机矩阵列表，支持新增、复制、删除；右侧名称与按输入列/输出行标注的 3×3 系数。CMOS 新增通过选择三张TIFF／RAW，后台自动识别、求解，展示 R/G/B 对应文件及系数，再命名保存；CMOS 系数只读，可重新选三张TIFF／RAW 计算、重命名、复制。标定与缺失原片重新定位的文件选择器共用 SourceImageIO 的 RAW 格式列表，格式与实际兼容条件见 [使用指南](user-guide.md#raw-格式)。密度矩阵允许逐项输入小数、负值及粘贴九个按行排列数值。非法或不足九项不能保存。

“保存到电脑”只更新本机矩阵库；“保存并应用到本卷”另以一次可撤销的卷事务应用新快照。应用到已校准卷会自动重新对齐片基，与矩阵合为一次撤销；保存到电脑不影响卷校准。等待期间保留原画面，失败提示真实读取/采样错误并保留原矩阵和校准；不因来源指纹或处理身份变化要求重新框选。当前卷使用的已删除或旧版预设显示为“本卷快照”，可继续渲染和保存；重新选择库中的版本才更新。改库不联动其他卷。关闭弹窗丢弃尚未保存的草稿，取消在途标定。弹窗、浮层和文本输入期间不触发调色快捷键。

导出统一使用Final，不提供独立CMOS校正输出。

## 最近胶卷

启动保持欢迎页，打开按钮下显示最近成功打开的胶卷：文件夹名称、路径、最近打开日期；单击打开并沿用上次 active 恢复规则。按打开时间倒序，同一规范化文件夹去重，最多20条，超过6行滚动。文件菜单提供同源的“最近打开的胶卷”。不读取原片生成封面。

悬停行尾×或右键“从最近记录中移除”仅删除本机历史，不改变原片与旁存项目，无确认弹窗；最后一次移除提供6秒撤销入口。再次打开重新记录。不可用位置保留并标注；点击可连接磁盘后重试或选取新位置，重新定位要求原项目UUID一致，成功才替换旧路径。导出期间禁用打开，切卷沿用保存失败保护。

## 整卷加载页面

新卷和旧卷使用同一“正在加载…”页面，显示进度条及“已完成 / 总数”（待检查的可用RAW张数），提供“取消加载”。加载期间不展示编辑控件、Filmstrip或主预览，不允许编辑/导出。所有代理成功就绪后进入编辑，才启动缩略图任务。有效缓存计入完成，自动清理后缺失的缓存先补齐；不以是否首次导入决定行为。RAW加载遇到源文件大小或修改时间变化时自动重试该张一次，已完成缓存保留；再次失败显示“加载未完成”、失败文件及原因，提供“重试”和“返回主页”，不进入半就绪编辑器。

## 预览工具栏

预览阶段入口固定命名“管线预览”，旁边显示当前选项；已有片基时仅提供“线性 / 密度 / 输出”，分别绑定 L2 / D3 / Final，默认输出。没有片基时仅显示不可选的“原图”，不提供处理阶段菜单。菜单以勾选显示当前项，不暴露其他内部阶段；“线性”是显示名称，TIFF 与 RAW 通用。阶段计算与显示转换继续遵守 pipeline.md。

裁剪/方向与管线预览两组，以留白及淡竖线分隔。方向使用四个图标按钮，管线预览使用原生菜单及单向下箭头；共用26pt内容高度、12pt字的外观组件，颜色跟随主题，悬停淡底。裁剪保留图标及文字，香槟金仅表示当前工具选中状态。

不提供“适应”按钮、缩放选中状态或双击复位；按钮旁的末尾分隔线一并删除。滚轮/手势缩放与平移始终使用当前1600代理预览，位置遵守上方边界。不提供100%按钮、显示菜单中的原始分辨率入口、⌘1快捷键或专用区域读取/细节叠加。

TIFF、RAW及混合胶卷都在整卷代理准备完成后进入编辑，统一加载进度、失败重试和取消。切帧命中匹配的正式预览缓存时立即恢复目标画面及匹配当前统计阶段的直方图；未命中时暂留上一张画面、显示几何、视口和直方图，目标正式预览就绪后一起替换，再按目标照片恢复默认尺寸与居中。不放大Final缩略图；缓存占位或暂留旧画面期间禁用精确取样、直方图悬停与裁剪编辑／提交，连续切帧不提交未正式显示帧的草稿。等待超过600ms才显示加载提示，读取失败清除暂留画面并显示错误。连续调色保留当前正式画面至新结果发布。

当前卷编辑器空闲时自动准备正式预览与直方图缓存，不需要逐张点开；以当前主预览照片为中心，先当前张，再前后相邻各一张，逐步向两侧扩展，最多40张。切图后以新的当前照片重排，切图、调色、取样、裁剪、分析或导出优先于后台准备；缓存仍为有界内存缓存，关闭或重开卷后按当前参数重新准备。


## 裁剪与同步

预览工具栏在方向图标左侧提供“裁剪”，R 进入。裁剪栏为单行：“长宽比”菜单、锁定按钮、“交换宽高”，与“角度”滑杆及只读两位小数角度以留白和竖线分隔；随后提供“重置”、检查操作、取消与完成。菜单提供“原始图像”、3:2、4:3、1:1、7:6及“输入自定值…”。自定值弹窗输入宽、高正数，比例范围1:10至10:1，非法值不能确定。原始图像按当前方向下的完整图像比例解释，仅改变比例、不重置范围。选择比例自动锁定；默认、进入新照片及自动裁剪后均锁定当前比例，解锁可独立改变宽高，再锁定保持当前比例。交换宽高取当前比例倒数，保留锁定状态。重置恢复全图、零角度和原始比例锁定，完成时才清除帧裁剪。

角度范围仍为±10°，滑杆双击归零，无加减按钮或数值输入框。鼠标在裁剪框外且预览视口内显示两端为实心三角箭头的双向弧形旋转光标，按裁剪框四边与四角的八个区域切换朝向，弧线凹面朝向裁剪框，黑色线芯配白色描边适应深浅背景，拖动按围绕原始图像中心的鼠标角度变化旋转；边角命中优先缩放，框内拖动仍移动裁框。松开于视口外恢复拖动前草稿。不提供画线拉直。

编辑时展示全图，框外暗色遮罩仅覆盖旋转后的照片范围，不压暗照片外的画布底色；保留网格、四角四边把手；框内拖动移动，固定比例时边角拖动保持比例，自由比例时可独立改变宽高。照片围绕全图中心旋转，框始终水平；显示角度与横竖按当前照片方向呈现，保存时转换为原片坐标。约束与自动收边由 pipeline.md §14 定义。Enter/完成只修改当前帧；Esc/取消恢复进入前裁剪，整次提交一次 Undo。R、Enter、Esc 仅无文本输入/弹窗时由编辑器处理。编辑中不触发方向变换或导出；无修饰键时 W/S/A/D 分别将裁剪框上/下/左/右移动约 0.3% 画面尺寸，系统按键重复可连续移动。Filmstrip 普通点击或左右方向键切换当前帧时保持裁剪模式，先提交上一张当前裁剪（含重置全图），登记一次撤销、刷新缩略图并立即自动保存，再按新照片自己的已保存裁剪初始化草稿（无裁剪时沿用进入裁剪的默认值）。加载期间禁用裁剪编辑和提交，⌘/Shift/⌘Shift 扩选保持当前照片和草稿。按住调色键的动作在进入裁剪时结束。

裁剪栏只编辑当前照片，完成后再使用 Filmstrip 上方统一同步入口。裁剪编辑期间同步禁用，提示先完成裁剪。同步的原片范围、细角度与方向保留规则见“复制与同步”及pipeline.md §14。

草稿在完成或切换照片时提交，此前不写项目或导出快照。未加载完成的照片在快速切图时不提交空草稿；点击当前照片或到达首尾不提交。Esc/取消仅丢弃当前照片草稿，已经切走的照片裁剪保持。保存失败显示原生错误提示，可通过文件菜单重试，保留内存裁剪与撤销。完成后自动保存，预览按裁剪预览开关恢复显示；Filmstrip与直方图使用已提交裁剪，导出遵循应用裁剪设置。片基取样的全图恢复规则见 pipeline.md §14。复制调色包含Timing、Contrast和LUT，不包含裁剪。

裁剪模式Q/E每次调整角度−0.1°／+0.1°；普通预览和裁剪复用同一画布，进入、完成或取消时保留旧画面直到新预览就绪。


## 裁剪预览

“管线预览”左侧提供“裁剪预览”复选框，默认勾选。取消勾选显示完整画面并隐藏裁剪微调角度，保留独立旋转/翻转与当前调色；直方图仍按已保存裁剪范围统计。开关是会话状态，切图和切卷保持，重启默认勾选，不写胶卷或导出偏好。裁剪编辑仍显示完整画面和草稿框，完成/取消后恢复开关指定的预览。切换时复位视口适应画面；吸管与悬停取样按当前显示几何映射。缩略图、自动分析、调色参数与导出不受开关影响。

## 自动裁剪与自由比例

自由调整由解锁按钮控制，不再作为比例菜单选项。锁定是裁剪编辑会话状态，旧项目与自动裁剪的自由比例存储也默认锁定，不重写既有裁框。

顶部在“重置调色”左侧依次显示“自动裁剪”“色罩分析”，移除预览工具栏的自动裁剪及TIMING标题行的魔棒入口。点击后打开设置对话框：画幅比例默认3:2，提供3:2、4:3、1:1、5:4、7:6、2:1、3:1与自定义；无自动识别比例选项。自定义输入宽、高正数（可含小数），“交换宽高”用于竖幅；有效比值范围1:10～10:1，非法输入显示错误并禁用开始。比例按原片坐标解释，选项仅用于本次运行、不记入项目；开始后锁定。“保留已裁剪”默认不勾选；勾选时保护手动、旧版和上次自动生成的全部现有裁剪，包括手动重置的全图；取消勾选则重算所有非缺失照片。“每边内收”使用下拉框，仅提供0%、1%、2%、3%、4%、5%六档，默认1%。对话框不显示说明小字，只保留选项、操作按钮和运行进度。开始后选项锁定，对话框保持打开并原位显示两遍分析进度和“取消分析”；分析运行时不能关闭对话框。整批结果一次提交、一次撤销，取消或失败不提交部分结果。

完成后，有待检查照片时自动关闭对话框、进入第一张待检查照片的裁剪模式，并默认“仅看待检查”；没有待检查时直接结束。人工检查的“待检查 N”菜单和“确认并下一张”显示在裁剪栏，“仅看待检查”位于该菜单内，待检查为0时全部隐藏；Filmstrip标题行不显示进度、状态或检查按钮。筛选同步作用于缩略图和左右键，原卷编号不变。回车（含数字键盘 Enter）与“确认并下一张”按钮执行同一操作，长按不重复确认。确认保存当前草稿、清除标记并前往下一张；最后一张确认后结束检查、恢复完整Filmstrip。关闭筛选可浏览整卷，切图仍自动保存裁剪。

待检查状态不在Filmstrip添加专用标记；人工检查期间由裁剪栏数量和“仅看待检查”筛选表达。检查标记与裁剪一起保存/撤销；筛选不写入胶卷。

## 直方图与取样

直方图位于预览右上角，Density／Final独立于画面阶段，默认Final，固定RGB叠加。收起状态本机记忆；直方图统计整张裁后预览，不随平移或缩放变化。72%不透明度浮层，绘图区有完整外框；横轴、纵轴及取样算法见pipeline.md。

Color Timing 标题右侧提供中性点吸管。点击或按 I 启用，预览内指针变吸管，尖端为取样点，点一次完成并退出；Esc/I/再次点击按钮取消。I 沿用窗口快捷键的文本输入、弹窗与失焦保护，长按不反复切换。片基框选状态在预览内显示十字指针；工具切换、取样完成和取消立即更新鼠标形状，无需移动。移出预览后由所在控件使用正常指针。片基框选与裁剪互斥，正式预览未准备好时禁用精确取样。采样范围为原片长边0.8%的方形，网格取整与边缘截短见pipeline.md §15；取样以邻域的 Final 中位数为中性目标，尽量保持最终亮度；目标和数值容差以 pipeline.md §15 为准。帮助文字标明 Final 中性，不随当前诊断阶段改变目标。只改变当前帧 RGB Timing，整次操作一次撤销并沿用保存、缩略图与复制语义。取样等待中切帧、调参、切阶段、改校准/几何或取消时丢弃结果；无效取样、无法收敛或整数精度不足等求解失败时直接结束取样，不弹窗、不重新载入照片，已有参数及撤销记录保留；文件读取或源变化错误仍沿用原错误处理。求解在后台进行，等待期间取消或继续调色会丢弃结果。

普通预览默认箭头，实际按住拖动画布时为闭合抓手，松开恢复箭头；吸管、片基十字和裁剪边缘指针保持。悬停照片时，直方图显示RGB三条半透明细线（45%不透明度，无底部三角或黑色描边；从底部延伸至各自通道在该横坐标的已绘制曲线高度，按相邻点插值），横坐标按直方图自身Density/Final阶段的邻域中位数定位；不增加常驻读数或照片取样框。取样契约见pipeline.md。照片外、直方图面板上、拖动期间、片基或裁剪模式和占位预览不显示；松开或回到照片后恢复。超过横轴范围的值显示在对应端点。

每条悬停标记线的曲线交点增加对应RGB颜色的实心圆点（直径5点，0.75点半透明浅色描边），帮助辨认位置；保留半透明短线，无底部三角。

## 整卷自动调色

顶部“色罩分析”调用整卷自动调色。分析需已存片基校准且当前矩阵与校准快照一致，不要求采样来源帧仍存在、不复核已存片基；裁剪、片基框选、自动裁剪、导出或加载期间不可调用。忽略多选范围，分析整卷可用帧的裁后画面。

没有片基时按钮可点击，仅显示原生“未框选片基”弹窗，按钮为“框选片基”和“取消”；前者关闭弹窗并启用片基框选，后者不改变设置。采样成功后不自动分析，由用户再次点击入口。有片基时点击先显示原生“色罩分析”确认弹窗，提示“将开始整卷色罩分析，请确认已完成有效画幅裁剪和片基框选”，增加“自动曝光”复选框，每次默认不勾选，提供“取消”和“开始分析”。确认后保持同一个系统弹窗，显示进度和“取消分析”；成功后仅显示标题“分析成功”，不显示RGB Timing值，下方为“保留已调色”（每次默认不勾选），按钮为取消和应用到整卷。失败时显示“分析未完成”、原因和取消，不提供应用按钮。

保留已调色仅保护Timing或Contrast非默认值的照片，LUT/裁剪/方向变化不算已调色；该选项只影响应用范围，不影响整卷统计。分析统一使用卷内第一张照片所选LUT。应用统一RGB、四项Contrast=1，并将目标LUT覆盖为分析时第一张照片的LUT；Master在关闭自动曝光时为0，开启时采用逐帧结果（见pipeline.md）。保留裁剪和方向；受保护照片全部调色及LUT保持。整卷一次撤销，之后可精调；取消无参数写入。

色罩分析、自定裁剪长宽比及自动裁剪设置/进度采用NSAlert系统外框、标题和按钮，附件容纳复选框、输入、选项及进度；不自绘警告框背景或按钮。自定比例非法时禁用确定，自动裁剪非法时禁用开始，运行期间设置锁定，原取消和待检查流程保持。已有原生错误、命名、导出设置、重名与退出提示沿用系统实现。复杂矩阵管理保留专用面板；缓存管理/快捷键为独立窗口，文件选择器保持系统实现。外观随macOS与深浅模式变化。


## 导出

当前照片、所选照片和整卷入口直接确定导出目标。独立设置窗口只显示目的地、文件名前缀、格式、色彩空间、ZIP 压缩和应用裁剪；点击目的地“选择…”才打开系统目录选择器，随后点击“导出”直接开始。未选目录、目录不可用或前缀非法时禁用导出。取消不保存草稿；点击导出时每卷保存目的地和输出选项。前缀默认随卷名，名称中的非法文件名字符在前缀中替换为下划线；手动改前缀后不再跟随卷名。ZIP 压缩以复选框呈现，仅在 TIFF 格式时显示，取消即无压缩。应用裁剪对 TIFF/JPG 均显示；关闭时导出完整画面并忽略裁剪微调角度，保留独立旋转/翻转，不改照片裁剪与预览。两项初始默认勾选，随后按卷记忆，旧项目缺少应用裁剪字段时按启用读取。自动追加胶卷完整顺序的一起始编号，至少两位，例如 `假日-02.tiff`；单独导出第二张仍为 02。重名时询问覆盖、自动重命名或取消，卷内原片始终禁止覆盖。

菜单顺序和名称为 sRGB IEC61966-2.1、Display P3、Adobe RGB (1998)、ProPhoto RGB、Rec. 2020。新卷默认 Display P3。读取旧 p3 或未知输出空间时，内存设置自动回退 Display P3 并更新对应 ICC 指纹，下次正常保存写回；有效选项保持。读取本身不直接写盘。转换定义见 pipeline.md §11。

顶部导出菜单显示“导出”，提供“导出选中 N 张…”和“导出整卷…”，不再重复提供当前照片选项；单选时通过导出选中一张导出当前照片，文件菜单及⌘⇧E仍可直接导出当前照片。格式下拉提供16-bit TIFF和8-bit JPG，初始TIFF，确认导出才保存选择，取消不写入。两种格式均提供现有五项输出ICC。JPG固定最高编码质量，隐藏ZIP压缩复选框；切回TIFF恢复已选压缩状态，初始默认勾选ZIP。输出扩展名随格式为.tiff或.jpg。

导出冻结提交时的目标与参数。点击导出后设置窗口保持打开，选项锁定，复选项下方、按钮上方的预留区域显示单行进度（张数/文件名、进度条和百分比）；取消按钮改为“取消导出”，取消等待期间禁用重复点击。结束后同一区域显示“导出成功”“导出失败”（含成功/失败张数）或“导出已取消”（含已完成张数），进度条隐藏，按钮为“关闭”；失败原因放在结果悬停提示中。关闭前不重复导出，不另弹逐张结果窗口，也不提供查看上次结果入口。运行中不能切卷，取消保留完成文件；设置 sheet 打开时主窗口输入由系统阻止，任务快照和底层可编辑能力保持。裁剪中的导出入口禁用。

主工具栏下方不再显示任何按需状态行，删除其中的导出进度/取消、保存失败/重试和图像准备文字。保存失败仍保留内存修改、原生错误提示、文件菜单保存和设置副本恢复入口。


## 管理缓存

File → 管理缓存… 在主页和编辑中均可打开独立窗口。显示“缓存大小 2.5/8.0 GB”（实际用量/已保存上限，十进制GB），打开期间每2秒刷新。缓存上限输入GB，按“应用”或Enter保存；允许0.1至100000的有限数值，非法输入提示且保持原设置。删除期限下拉提供3天、7天、30天、永不，选择立即保存。本机记忆，默认8GB/30天；期限按最后使用时间，永不只关闭按天删除，容量淘汰仍生效。容量设置和期限均作用于所有系统缩略图与RAW持久缓存，超限先删最久未使用项。应用退出时不运行清理，下次启动补做；后台清理可能等待正在读取/导出的RAW完成。窗口不显示清理策略说明小字，不添加项目参数或撤销操作。


主页“打开底片”右侧增加带硬盘图标的“管理缓存”次级按钮；打开文件夹保留金色主按钮，缓存使用标准边框按钮。两个入口复用同一个独立缓存窗口，空历史与最近胶卷状态均可用。移除缓存窗口底部整段清理策略说明。

## 深浅外观

PRINTROOM 旁的太阳／月亮开关切换浅色／深色，即时应用到主窗口、辅助窗口及原生对话框。macOS 菜单栏移除“外观”“批量输出”“调色”三个独立菜单；外观开关、窗口导出入口及复制／粘贴快捷键和缩略图右键入口保持。本机记忆，重启保持；首次使用沿用深色。照片画布遵循下方语义色规范；主页背景随主题变化。工具栏、调色区、直方图与缩略图选中状态适配主题，外观不写入胶卷项目。

## 胶卷命名与导出设置

主页按钮显示“打开底片”，仍使用系统文件夹选择器。没有已有项目的新卷在整卷成功加载后自动弹出原生“命名胶卷”对话框；取消沿用文件夹名，保存和取消后重开已有项目均不再自动提示。加载失败、取消或被另一卷替换时不弹出命名框，失败后重试成功仍按新卷提示。Filmstrip 数量左侧显示卷名及命名铅笔，名字右侧另有文件夹图标，在 Finder 中打开当前底片文件夹；顶部工具栏不再显示卷名和命名入口。主页最近胶卷右键也可重命名。清空自定义名称恢复文件夹名；主页保留路径以区分同名卷。卷名存于卷内项目，不更改文件夹或原片。导出设置按“导出”一节执行，导出范围由入口确定。

## 品牌与 Filmstrip 卷名层级

PRINTROOM 品牌显示图标和品牌字标，字标右侧为64×30pt分段胶囊外观开关，左侧太阳、右侧月亮始终同时显示；当前外观以独立高亮底和香槟金图标标记，另一侧使用次要文字色。点击太阳选择浅色、点击月亮选择深色，提供悬停底色和外观提示。使用本机外观偏好，主页和加载时同样可用。打开胶卷后，卷名在 Filmstrip 的“xx 张 · 已选 xx 张”左侧显示，使用主文字颜色和半粗字体；编辑铅笔与 Finder 文件夹按钮紧随卷名。长名称在可用空间内中间截断，悬停可查看完整名称。主页不显示卷名。卷名和文件夹名相互独立。

## 界面文字与滚动

缩略图栏不显示FILMSTRIP标题，保留总数和已选数量；复制快照状态显示“已复制：文件名”。预览尺寸不常驻，移到预览文件名的悬停提示中。缓存窗口不重复显示“管理缓存”内容标题。矩阵分组的入口简写为“管理…”，常规成功反馈仅显示“已应用”“已保存”“已删除”或“已计算”。缩略图右键使用“复制调色（⌘C）”“粘贴调色（⌘V）”；导出摘要的取消项只写“已取消”。操作对象、批量数量、整卷作用范围、错误原因与覆盖确认保持明确。

界面以控件名称、布局、悬停提示和辅助功能标签表达含义；只保留必要的错误、进度和操作确认，不增加常驻说明小字。Filmstrip和右侧面板使用AppKit浮动滚动条，不修改系统全局偏好；Filmstrip保留112点独立缩略图滚动区域。


## 整卷齿孔置白

用户确认入口置于顶部“自动裁剪”左侧，作为整卷调节。点击“齿孔置白”打开浮层，包含默认关闭的“齿孔置白”开关和识别阈值滑杆，不重复显示标题；阈值范围/默认与识别规则以pipeline.md为准，读数显示“片基 +N%”。设置即时预览，不依赖当前多选范围，不参与逐帧调色复制或同步；开关一次撤销，连续拖动滑杆整体一次撤销，保存及重开恢复。

至少一张可用照片具有裁框且片基已校准时才能启用；未满足时提示先完成片基校准和裁剪。正常状态不显示底部说明小字。已存片基来源变化不暂停已保存的启用状态。没有裁框的照片保持原样。加载、导出、裁剪编辑及自动裁剪运行期间入口禁用；采样期间暂停处理。

取消“裁剪预览”可检查完整底片上的白色齿孔，保持裁后直方图统计；导出取消“应用裁剪”才保留齿孔。该功能不修改裁框、调色或输入样本。
