# 编辑与复制/应用交互

状态：2026-09-09，0.3.4。复制快照、覆盖应用、整组撤销，以及多选保持当前编辑帧、原片裁剪同步和单行裁剪栏均按用户确认执行；其余细节为工程默认。

## 布局与单张编辑

主预览在左、调色面板在右，Filmstrip 位于底部。调色面板按编号依次显示：01 矩阵矫正（左 CMOS 矩阵、右密度矩阵）、02 Film Base 对齐、03 Color Timing、04 RGB Contrast。Film Base 对齐与矩阵矫正为独立分组，均作用于整卷；片基来源复核提醒留在对齐分组。输出选项在导出对话框中显示。主预览支持缩放、平移、片基矩形选区、阶段切换与中性点吸管。

双指滑动按 macOS 滚动事件的方向平移照片，遵循系统“自然滚动”设置，不额外反转水平或垂直位移。

预览视口由页面剩余空间决定；缩放和平移只改变视口内的图像变换，不参与页面尺寸计算。SwiftUI 容器、AppKit Canvas 及绘图上下文都裁切到此边界，图像与选区不得覆盖工具栏、右侧面板或 Filmstrip。片基选区同时受图像与视口交集约束。

鼠标按下、滚轮、捏合和取样只响应视口内位置；拖出时暂停平移/框选，重入不累计窗外平移量，窗外松开取消提交。窗口改变尺寸时取消进行中的拖动，避免混用两套坐标。取样仍按完整 imageRect 逆映射到 orientation 校正后的原始尺寸，不用可见裁切矩形拉伸映射。“适应窗口”、双击和切帧统一清除平移与临时选区并恢复居中 fit。TIFF 方向校正在导入阶段完成，用户追加方向见下方方向操作。

面板始终编辑当前主预览帧 `activeFrameID`，即使选中多张，拖动控件也只修改当前帧。批量修改通过明确的“应用”按钮进行。当前文件名统一显示在预览工具栏，Filmstrip 突出当前帧；调色面板不再重复“当前照片”或“正在编辑”文字。

## 当前帧、选择集合与锚点

维护三个独立状态：`activeFrameID`、`selectedFrameIDs`、`selectionAnchorID`，均使用稳定帧 ID。非空选择中 active 必须是集合成员。当前帧突出边框，其他选中帧使用选择背景；两种状态不能只有不可辨认的细微色差。

| 操作 | 行为 |
| --- | --- |
| 普通点击 | 集合替换为该帧，该帧成为 active 和 anchor |
| ⌘ 点击未选中帧 | 加入目标集合，保持 active 和 anchor |
| ⌘ 点击已选中非当前帧 | 从目标集合移除，保持 active 和 anchor |
| ⌘ 点击当前帧 | 不改变选择；active 始终保持选中 |
| Shift 点击 | 从普通点击确定的 anchor 到目标（含端点）替换连续目标集合，保持 active 和 anchor，并确保 active 仍在集合中；无 anchor 则等同普通点击 |
| ⌘Shift 点击 | 将 anchor 至目标区间加入原集合，保持 active 和 anchor |
| ⌘A（无文本输入焦点） | 全选当前卷可用帧，保留 active；无 active 则取第一张 |

⌘/Shift/⌘Shift 只修改批量目标，不切换主预览，不取消裁剪草稿，也不复位缩放或平移；普通点击才切换 active 并重新确定 anchor。没有 active 的初始状态以首个有效点击建立 active 和 anchor。排序变化按稳定 ID 保留选择，后续 Shift 范围以新顺序为准；外部源变化导致 active 不再可用时才按可用集合修复选择。缺失/不可用文件保留条目但不可加入选择；若已选文件在应用前丢失，应用失败且不修改任何帧。

## 复制调色

⌘C 复制当前帧参数，⌘V 应用到所选照片，替代原 ⌘⇧C/⌘⇧V。由编辑器窗口路由；文本编辑、弹窗及失焦时保留系统行为，长按不重复操作。

“复制调色”从 active 帧生成不可变快照，包含四个整数 Timing、四个 Contrast，以及快照格式版本、算法版本、固定 pivot 标识、来源帧 ID 与显示文件名。

不复制：片基选区、base、Linear Gain、自动偏移、矩阵、LUT、输入解释、方向、裁剪、输出 profile、选择状态、缩放与缓存。

无 active 时按钮禁用；多个选中项不影响来源。快照一旦复制，不随来源照片后续修改而变化。界面显示“已复制：文件名”。快照只在当前卷会话内保存在内存，不写系统剪贴板，不写项目；切换卷或退出时清空，避免无意跨卷应用。来源帧之后丢失不影响已经保存的快照值。

## 粘贴调色

粘贴有快照且选择非空才启用。菜单显示“粘贴调色到所选照片”，N 包含集合内全部目标；只选一张时应用到该张。点击时捕获快照和目标 ID 列表，不因异步渲染或后续选择改变目标。

1. 校验快照格式/算法兼容性、每个目标可用性与参数范围。
2. 整组覆盖目标帧的 Timing 和 Contrast，不加算、不乘算、不修改卷级校准。
3. 在一个事务中更新模型，一次性登记 undo，标记项目待保存并更新受影响缩略图。
4. 显示“已应用到 N 张”；不会改变当前选择或 active。

任一目标无效则整组失败，不产生部分应用。若所有目标原本已相同，则提示“所选照片参数已相同”，不增加无意义撤销记录。来源照片也在目标中时按同一规则覆盖。普通批量应用不弹确认对话框。

## 撤销与保存

一次应用对应一次 UndoManager 操作，每帧分别保存应用前参数；⌘Z 一次恢复全部，Redo 一次重新应用。手动滑块从按下到松开作为一组撤销，数值提交一次为一组。

重新采样是一次卷级事务与撤销，恢复相关 base/gain/offset 及采样时矩阵快照。切换矩阵是独立卷级事务，只改当前矩阵并可撤销，不重做片基对齐；保持帧级用户参数。撤销栈仅会话内有效，重开项目不恢复历史。复制不进入撤销栈。

应用后立即安排自动保存；保存失败保留内存参数和撤销能力，显示未保存状态与重试入口，不能错误提示“已保存”。保存策略见 [architecture.md](architecture.md)。

## Timing 快捷键

| 按键 | 操作 |
| --- | --- |
| Q / E | Red −1 / +1 CV |
| A / D | Green −1 / +1 CV |
| Z / C | Blue −1 / +1 CV |
| W / S | Master +1 / −1 CV |
| [ / ]（【 / 】） | 当前照片左旋转 / 右旋转 90° |
| ⌘F | 当前画面水平翻转 |
| ← / → | 上一张 / 下一张可用照片 |
| I | 开启 / 取消中性点吸管；长按不反复切换 |

窗口内无文本输入焦点、无弹窗、未进入裁剪且没有 Command/Control 修饰时生效。点击 Filmstrip 先提交数值输入并结束文本焦点，随后可以直接调色；不再存在 Filmstrip 专属调色焦点模式。无 Option 调 Timing，有 Option 调对应 Contrast。⌘A 在无文本焦点时全选照片，在文本内保留全选文字；⌘C/⌘V 在无文本焦点时复制/应用参数，在文本内保留文字复制/粘贴；⌘Z 和文本输入法不被调色字母键截获。单击每次 1 CV，Shift + 快捷键单击每次 10 CV。按住约 0.4 秒后由应用计时，以固定 25 CV/秒连续调节，不渐进加速，Shift 不放大连续速率；不依赖 macOS 键盘重复设置。松手立即停止；换键重新计时，切帧、失焦或弹窗时终止。一次按住到松开对应一次撤销/重做，到达控件范围即停止变化且不追加空撤销。滑杆、输入框及快捷键共享 [pipeline.md §7](pipeline.md#7-timing-与-rgb-contrast) 的范围。

## Filmstrip 与卷级状态

Filmstrip 可用帧的右键菜单提供“水平翻转x张底片”“垂直翻转x张底片”“顺时针旋转x张底片”“逆时针旋转x张底片”，x 为当前选中集合数量（包含当前帧）。右键不改变选择；操作作用于所选集合，每帧基于自己的当前画面翻转或旋转 90°，保留原片裁剪与调色。整组校验、一次撤销/重做、自动保存并刷新受影响缩略图；缺失目标则全部不改。裁剪编辑、胶卷加载或无选择时禁用。预览工具栏与快捷键仍只改变当前帧。

缩略图显示文件名、序号、当前/选中状态，以及帧级参数是否偏离默认值。校准状态来自整卷，可显示统一卷级标记；不能因为某帧 Timing 不为零就标记为未校准。

卷级校准改变会影响全卷预览与缓存，无需逐张“应用校准”。未校准时用户可继续编辑和导出；调色面板不再显示常规校准数值与说明，只有片基来源变化需复核时显示操作提醒。首次打开只选中被打开的 TIFF；重开卷可恢复上次 active，明确打开另一张 TIFF 时以该文件为准。

## 0.2.0 新增操作

预览工具栏及“方向”菜单提供顺/逆时针 90°、当前显示方向水平/垂直翻转、重置。每次只改变 active 帧的方向，形成一次 Undo/Redo，重开恢复。组合与原始坐标见 [pipeline.md §10](pipeline.md#10-020-用户方向与原始坐标)。复制/应用仍然只含 Timing 和 Contrast，方向、输出设置不混入快照。

“1:1”/⌘1 使一个原片像素对应一个物理显示像素（Retina 使用 backing scale），居中读取当前可见原始区域；继续平移按需更新，读取中显示状态。适应窗口/双击/切帧/改方向复位视口。高倍缩放用原始区域覆盖低分辨率底图，像素不做精度降级；整图直方图保持独立。

整图预览直方图位于预览视口右上角，以半透明深色浮层显示，顶部仅提供 Density / Final 切换，默认 Final，始终叠加 RGB 三通道。Density 对应 D3；直方图阶段独立于照片预览阶段，切图沿用，重启默认 Final。右上角箭头按钮可收起整个图表，收起后仅保留紧凑的“直方图”展开按钮；初次默认展开，本机偏好记住状态，切图、裁剪返回及重启沿用，不写入胶卷项目。图表随窗口定位、不参与照片缩放；移除信息按钮与详细统计弹窗。片基框选提示放在预览底部，避免与直方图重叠。

Color Timing 与 RGB Contrast 共用横向滑杆样式，从上到下以白、红、绿、蓝表示 Master/R/G/B，不显示通道文字。右侧数值可输入；Timing 不显示 CV 后缀。通道名称保留在悬停提示和辅助功能标签中；键盘步长与连续调节遵循上文 Timing 快捷键规范，参数范围见 pipeline.md，整组撤销语义保持。移除 BASE/GAIN/OFFSET、校准成功说明、快捷键小字、Pivot 行及管线说明。

当前照片、所选照片和整卷导出均在目录对话框内显示文件名前缀、五种输出 ICC、无压缩/ZIP 和 16-bit TIFF 格式。每次打开默认 ZIP（TIFF 内部 Deflate 无损压缩），ICC 载入本卷上次选择；取消不保存草稿，确认导出才保存输出设置并固定任务快照，不影响预览。前缀初始为胶卷文件夹名，可修改；自动追加胶卷当前完整顺序的一起始编号，至少两位，例如 `假日-02.tiff`。编号在筛选目标前确定，单独导出第二张仍为 02，超过 99 不截断。前缀不能留空或包含路径分隔符；重名继续追加冲突后缀，不覆盖已有文件。

导出菜单提供当前照片、选中集合、整卷三种入口。三种入口统一选择目录并指定前缀。任务开始时固定目标及设置，此后可以调色、改变选择、Undo/Redo、旋转，不影响正在执行的任务；切换胶卷和退出须先完成或取消导出。进度显示照片及总体数量；结果逐张列出成功路径、失败原因、取消或未开始，用户可在 Finder 显示成功文件。单张失败继续其他帧，取消保留已完成并清理未完成临时文件。

缺失帧保留在 Filmstrip，右键“重新定位此照片”选择卷内 TIFF。手动重连保留稳定 ID、调色和方向；目标已被其他编辑帧占用时拒绝合并，原路径仍可读时拒绝误重连。片基来源重连后提示复核。File 的“管理缓存…”打开独立缓存管理窗口；导出菜单可再次查看上次结果。

旋转、翻转及左右切图在编辑器窗口生效，包含预览、滑杆和Filmstrip焦点；文本输入、输入法组合及弹窗期间不拦截。四个方向键不再调节滑杆；↑/↓无调色动作。左右切图采用单选、跳过缺失帧，首尾停止、不循环；无当前帧时选择第一张可用照片。旋转与翻转沿用原有单次撤销和帧级保存。


连续调参时主预览持续显示按顺序完成的参数快照，停止输入后收敛到最后参数；切图、阶段、校准、方向变化不显示旧上下文的结果。整图直方图在最新预览稳定后更新；高频输入期间保持上一份完整统计，不清空、不显示转圈或更新提示，完成后直接替换。切帧、阶段或校准/几何上下文变化清除不匹配统计。保存、撤销、调色步长与范围不变。


## 0.3.1 裁剪与同步

预览工具栏在“方向”旁提供“裁剪”，R 进入。裁剪栏为单行：比例菜单、横竖切换、角度减/滑杆/加、两位小数角度输入、重置、取消与完成。比例提供 3:2、4:3、1:1、7:6；滑杆范围 ±10°，按钮每次 0.1°，输入精确到 0.01°，双击滑杆归零。栏内不显示输出尺寸或常驻说明，名称与帮助通过悬停和辅助功能保留。没有画线自动拉直工具。重置裁剪显示“全图”，属于草稿，完成时才清除帧裁剪。

编辑时展示全图，框外暗色遮罩仅覆盖旋转后的照片范围，不压暗照片外的画布底色；保留网格、四角四边把手；框内拖动移动，边角拖动保持当前比例。照片围绕全图中心旋转，框始终水平；显示角度与横竖按当前照片方向呈现，保存时转换为原片坐标。约束与自动收边由 pipeline.md §14 定义。Enter/完成只修改当前帧；Esc/取消恢复进入前裁剪，整次提交一次 Undo。R、Enter、Esc 仅无文本输入/弹窗时由编辑器处理；角度输入 Enter 先提交数值。编辑中不触发方向变换、1:1 或导出；无修饰键时 W/S/A/D 分别将裁剪框上/下/左/右移动约 0.3% 画面尺寸，系统按键重复可连续移动。Filmstrip 普通点击或左右方向键切换当前帧时保持裁剪模式，先提交上一张当前裁剪（含重置全图），登记一次撤销、刷新缩略图并立即自动保存，再按新照片自己的已保存裁剪初始化草稿（无裁剪时沿用进入裁剪的默认值）。加载期间禁用裁剪编辑和提交，⌘/Shift/⌘Shift 扩选保持当前照片和草稿。按住调色键的动作在进入裁剪时结束。

裁剪栏只编辑当前照片，完成后再使用 Filmstrip 上方统一同步入口。裁剪编辑期间同步禁用，提示先完成裁剪。同步的原片范围、细角度与方向保留规则见下方统一同步及 pipeline.md §14。

草稿在完成或切换照片时提交，此前不写项目或导出快照。未加载完成的照片在快速切图时不提交空草稿；点击当前照片或到达首尾不提交。Esc/取消仅丢弃当前照片草稿，已经切走的照片裁剪保持。保存失败沿用顶部未保存提示和重试，保留内存裁剪与撤销。完成后自动保存并适应裁后画面，主预览、Filmstrip、直方图、1:1 与导出使用已提交裁剪。缩略图的编辑状态包含裁剪。片基取样的全图恢复规则见 pipeline.md §14。“复制调色/粘贴调色”继续仅包含 Timing 和 Contrast。


## 0.3.2 编辑器精简与中性点

顶部“重置调色”，仅重置当前帧 Timing/Contrast，一次撤销，无确认弹窗；右侧调色面板不再重复重置按钮。普通点击预览不取样，原像素读数功能及整条读数栏移除。底部“已保存”常驻栏移除；保存失败才显示顶部重试入口，导出期间顶部临时行显示进度与取消，导出结果继续按需查看。1:1 状态并入原按钮，区域读取失败有可见错误提示。

Color Timing 标题右侧提供中性点吸管。点击或按 I 启用，预览内指针变吸管，尖端为取样点，点一次完成并退出；Esc/I/再次点击按钮取消。I 沿用窗口快捷键的文本输入、弹窗与失焦保护，长按不反复切换。片基框选状态在预览内显示十字指针；工具切换、取样完成和取消立即更新鼠标形状，无需移动。移出预览后由所在控件使用正常指针。片基框选与裁剪互斥，正式预览未准备好时禁用精确取样。0.3.43起采样范围为原片长边0.8%的方形，网格取整与边缘截短见pipeline.md §15；取样以邻域的 Final 中位数为中性目标，尽量保持最终亮度；目标和数值容差以 pipeline.md §15 为准。帮助文字标明 Final 中性，不随当前诊断阶段改变目标。只改变当前帧 RGB Timing，整次操作一次撤销并沿用保存、缩略图与复制语义。取样等待中切帧、调参、切阶段、改校准/几何或取消时丢弃结果；无效取样、无法收敛或整数精度不足等求解失败时直接结束取样，不弹窗、不重新载入照片，已有参数及撤销记录保留；文件读取或源变化错误仍沿用原错误处理。求解在后台进行，等待期间取消或继续调色会丢弃结果。

Option + Q/E、A/D、Z/C、W/S 按同一正负方向调整 RGB/Master Contrast，每次单击 0.01；Option+Shift 也为 0.01。长按延迟与原 Timing 相同，之后固定每秒 0.10，无 Shift 加速；一次按下至松开一组撤销。按实体键码路由，避免 Option 死键产生的特殊字符干扰；修饰键变化、松键、失焦、弹窗或切帧均停止。

所有密度阶段 D0–D3 直方图显示 0…1024 CV，95、470、685 位置使用轻淡参考线与数字，不增加黑点/灰点/白点说明文字；其余阶段仍显示 0…1。统计范围与 bins 不改变，转换规则见 pipeline.md §12。构建 3 起直方图采用整图均匀取样（小图精确），与对应正式画面同时替换；统计仍采用整图均匀取样；0.3.26 起不再提供详情弹窗。

切帧立即显示匹配该帧当前设置的已缓存主预览，未命中则使用匹配的 Final 缩略图；正式预览完成后原位替换，无淡入淡出、无中央加载浮层。没有任何占位图且等待超过 600ms 时才显示角落小提示。占位图只用于显示，不开启片基/吸管/裁剪/1:1 等精确操作。缓存身份、容量及失效规则见 architecture.md。


## 0.3.4 统一同步（用户确认）

Filmstrip 上方右侧固定“同步…”入口，多选时启用；选择计数包含当前照片，浮层目标与执行按钮明确为“其余 N 张”，排除当前照片。当前帧突出边框，其他目标显示选中背景。控件仍只编辑当前帧。

浮层显示当前来源文件名和目标数量，提供“调色 · Timing 与 Contrast”和“裁剪 · 范围与精细角度”两个复选框。**每次打开均不勾选**，至少选一项才可应用；不记忆上次选择。取消、点外部关闭不修改项目。切换当前帧或选择集合关闭浮层，避免来源和目标悄悄变化；浮层内不触发主窗口调色快捷键。

应用捕获当前照片的已提交设置和其余所选目标，不依赖复制快照。仅覆盖勾选内容；裁剪遵循 pipeline.md §14，包含细角度，全图来源可清除目标裁剪，保留每帧方向；卷级校准始终保留。全体目标先校验，任一失败整组不变。调色和裁剪一起选择也只产生一次事务与撤销；相同结果不增加撤销记录。完成后刷新目标缩略图并安排保存，来源帧和选择保持。

顶部移除复制/应用按钮，裁剪栏移除同步按钮。⌘C/⌘V 保留原调色快照语义，编辑菜单及胶片栏右键菜单称为“复制调色 / 粘贴调色到所选照片”；右键菜单明确复制来源为当前照片，粘贴覆盖全部所选照片。裁剪完成/取消只处理当前帧。


## 0.3.5 双矩阵管理

“01 矩阵矫正 · 整卷”标题右侧提供“管理…”，点击浮层选择 CMOS 矩阵或密度矩阵，再打开对应管理弹窗。主面板两列分别为左 CMOS、右密度矩阵。新建胶卷默认 CMOS 为 Sony A7C II、密度为 LED Light Source；两侧仍可选 Identity，已有胶卷读取保存的选择。内置项带锁，只读、可复制，不能编辑或删除。

管理弹窗左侧为内置和本机矩阵列表，支持新增、复制、删除；右侧名称与按输入列/输出行标注的 3×3 系数。CMOS 新增通过选择三张 TIFF，后台自动识别、求解，展示 R/G/B 对应文件及系数，再命名保存；CMOS 系数只读，可重新选三张 TIFF 计算、重命名、复制。密度矩阵允许逐项输入小数、负值及粘贴九个按行排列数值。非法或不足九项不能保存。

“保存到电脑”只更新本机矩阵库；“保存并应用到本卷”另以一次可撤销的卷事务应用新快照。应用到已校准卷会自动重新对齐片基，与矩阵合为一次撤销；保存到电脑不影响卷校准。等待期间保留原画面，失败提示并保留原矩阵和校准。当前卷使用的已删除或旧版预设显示为“本卷快照”，可继续渲染和保存；重新选择库中的版本才更新。改库不联动其他卷。关闭弹窗丢弃尚未保存的草稿，取消在途标定。弹窗、浮层和文本输入期间不触发调色快捷键。

0.3.17 起移除独立 CMOS 校正 TIFF 导出菜单，保留当前照片、所选照片、整卷的 Final TIFF 导出及上次导出结果。

## 0.3.6 RAW 交互

打开和卷内重新定位允许 TIFF / ARW；输出仍是 TIFF。首版 ARW 依赖安装在“应用程序”中的 Adobe DNG Converter，缺失、不支持输入、错误输出或超时明确报错，提供“重新载入照片”重试，不能自动切换去马赛克后端。打开卷仅发现原片，优先准备当前帧，Filmstrip后台固定4路准备，切帧按新当前照片重新排队。

RAW 初次载入显示图像准备状态，预览就绪后才允许基于尺寸的精确操作。0.3.13起，RAW的1:1、中性点与片基读取代理数据；等待时显示原始图像准备状态，切帧、取消或修改上下文不提交过期结果。全尺寸准备失败不导出小代理。调参不重新执行Adobe；现有同步、复制、单组撤销和固定导出快照语义保持。

0.3.7：Adobe默认静默运行，不占用Dock普通应用位置；RAW准备固定4路，无需用户设置。保持等待状态、取消和错误重试入口。

## CMOS 内置机型与 RAW 标定入口

CMOS 内置列表提供 Identity 和 Sony A7C II；均不可改名、编辑或删除，可复制。密度内置列表仍为原两项。新增 CMOS 后选择三张 TIFF / RAW，当前 RAW 支持 ARW，依赖已安装 Adobe DNG Converter。计算失败或取消保持原矩阵，成功后由用户保存或应用。切换机型自动沿已存片基选区重新对齐，遵循 pipeline.md §6。

## 0.3.14 预览工具栏

按用户确认，预览阶段入口固定命名“管线预览”，旁边显示当前选项；仅提供“线性 / 密度 / 输出”，分别绑定 L2 / D3 / Final，默认输出。菜单以勾选显示当前项，不暴露其他内部阶段；“线性”是显示名称，TIFF 与 RAW 通用。阶段计算与显示转换继续遵守 pipeline.md。

裁剪/方向、管线预览、缩放分三组，以留白及淡竖线分隔。方向与管线预览共用原生菜单及同一外观组件：26pt内容高度、12pt字、单向下箭头，默认浅灰，悬停淡底。裁剪保留图标及文字，香槟金仅表示当前工具/缩放选中状态。

## 0.3.16 原位裁剪

普通预览与裁剪始终复用同一个画布。裁剪栏原位替换顶部38点预览工具栏，不新增一行，进入/完成/取消不改变画布边界。切换期间保留旧照片、对应尺寸、旋转、裁剪遮罩与已有细节图；待新图就绪后一起替换并适应目标构图，不清屏、不淡入淡出。旧画面等待替换时暂停画布手势和精确取样，避免按新几何解释旧图。裁剪阶段仍展示完整原片并预留旋转空间，因此已裁剪或放大的照片在切换就绪时会调整构图。裁剪参数、快捷键、提交/取消与同步语义沿用上文。


## 0.3.16 快捷键帮助

裁剪模式下，无修饰键 Q/E 分别减少/增加显示角度，每次 0.1°，系统按键重复可连续调整，限于 ±10°。沿用角度按钮的草稿与方向转换；重置全图后也可直接调角度。文本输入、弹窗、失焦和照片加载期间不调整，完成或切图时按既有裁剪事务提交。

“帮助 → 键盘快捷键…”或 ⌘⇧/ 打开独立单实例帮助窗口，未打开胶卷时也可用。固定标题与修饰键图例，内容可滚动，按调色、反差、照片预览、选择与快照、文件编辑、帮助窗口分组，说明步长、长按、裁剪及文本焦点限制；附修饰键多选手势和标准窗口操作。帮助窗口获得焦点时既有编辑器路由停止调参；关闭用标准 ⌘W。快捷键内容以既有交互规范和实际路由为准。

## 0.3.34 管理缓存

移除主窗口顶部三个点按钮及其两项清理浮层。File → 管理缓存… 在主页和编辑中均可打开独立窗口。显示“缓存大小 2.5/8.0 GB”（实际用量/已保存上限，十进制GB），打开期间每2秒刷新。缓存上限输入GB，按“应用”或Enter保存；允许0.1至100000的有限数值，非法输入提示且保持原设置。删除期限下拉提供3天、7天、30天、永不，选择立即保存。本机记忆，默认8GB/30天；期限按最后使用时间，永不只关闭按天删除，容量淘汰仍生效。容量设置和期限均作用于所有系统缩略图与RAW持久缓存，超限先删最久未使用项。应用退出时不运行清理，下次启动补做；后台清理可能等待正在读取/导出的RAW完成。窗口不显示清理策略说明小字，不添加项目参数或撤销操作。


0.3.34 构建2：主页“打开底片文件夹”右侧增加带硬盘图标的“管理缓存”次级按钮；打开文件夹保留金色主按钮，缓存使用标准边框按钮。两个入口复用同一个独立缓存窗口，空历史与最近胶卷状态均可用。移除缓存窗口底部整段清理策略说明。
## 界面文字偏好

## 0.3.39 自动裁切与自由比例

裁剪比例菜单新增“自由”；切换时保持当前框，边和角可独立改变宽高，自由时禁用横竖比例交换。未裁照片初次进入裁剪以全图自由比例开始；重置后的角度控件与Q/E也使用全图自由比例。固定比例、Q/E和其他快捷键保持。

普通预览在“裁剪”左侧独立显示“自动裁切”。点击后打开设置对话框：“保留已裁切”默认不勾选；勾选时保护手动、旧版和上次自动生成的全部现有裁切，包括手动重置的全图；取消勾选则重算所有非缺失照片。“每边内收”使用下拉框，仅提供0%、1%、2%、3%、4%、5%六档，默认1%。对话框不显示说明小字，只保留选项、操作按钮和运行进度。开始后选项锁定，对话框保持打开并原位显示两遍分析进度和“取消分析”；分析运行时不能关闭对话框。整批结果一次提交、一次撤销，取消或失败不提交部分结果。

完成后，有待检查照片时自动关闭对话框、进入第一张待检查照片的裁剪模式，并默认“仅看待检查”；没有待检查时直接结束。人工检查的“待检查 N 张”“仅看待检查”和“确认并下一张”均显示在裁切栏，待检查为0时全部隐藏；Filmstrip标题行不显示进度、状态或检查按钮。筛选同步作用于缩略图和左右键，原卷编号不变。回车（含数字键盘 Enter）与“确认并下一张”按钮执行同一操作，长按不重复确认；角度输入框中仍先提交数值。确认保存当前草稿、清除标记并前往下一张；最后一张确认后结束检查、恢复完整Filmstrip。关闭筛选可浏览整卷，切图仍自动保存裁剪。

待检查状态不在Filmstrip添加专用标记；人工检查期间由裁切栏数量和“仅看待检查”筛选表达。检查标记与裁剪一起保存/撤销；筛选不写入胶卷。
