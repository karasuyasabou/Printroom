# 编辑与复制/应用交互

状态：复制快照、覆盖应用、多选目标、整组撤销已获用户确认。其余细节为 2026-09-07 工程默认。

## 布局与单张编辑

主预览在左、调色面板在右，Filmstrip 位于底部。面板分 Film Base、Timing、RGB Contrast、Pipeline、Export。主预览支持缩放、平移、片基矩形选区、阶段切换与 RGB 读数。

预览视口由页面剩余空间决定；缩放和平移只改变视口内的图像变换，不参与页面尺寸计算。SwiftUI 容器、AppKit Canvas 及绘图上下文都裁切到此边界，图像与选区不得覆盖工具栏、读数条、右侧面板或 Filmstrip。片基选区同时受图像与视口交集约束。

鼠标按下、滚轮、捏合和取样只响应视口内位置；拖出时暂停平移/框选，重入不累计窗外平移量，窗外松开取消提交。窗口改变尺寸时取消进行中的拖动，避免混用两套坐标。取样仍按完整 imageRect 逆映射到 orientation 校正后的原始尺寸，不用可见裁切矩形拉伸映射。“适应窗口”、双击和切帧统一清除平移与临时选区并恢复居中 fit。当前没有独立手动旋转/翻转命令；TIFF 方向校正在导入阶段完成。

面板始终编辑当前主预览帧 `activeFrameID`，即使选中多张，拖动控件也只修改当前帧。批量修改通过明确的“应用”按钮进行。多选时面板显示“正在编辑：文件名”，不把当前帧参数伪装成所有选中帧的共同值。

## 当前帧、选择集合与锚点

维护三个独立状态：`activeFrameID`、`selectedFrameIDs`、`selectionAnchorID`，均使用稳定帧 ID。非空选择中 active 必须是集合成员。当前帧突出边框，其他选中帧使用选择背景；两种状态不能只有不可辨认的细微色差。

| 操作 | 行为 |
| --- | --- |
| 普通点击 | 集合替换为该帧，该帧成为 active 和 anchor |
| ⌘ 点击未选中帧 | 加入集合，并成为 active 和 anchor |
| ⌘ 点击已选中帧 | 从集合移除；移除 active 时，按 Filmstrip 顺序选最近剩余帧，距离相同取前一张 |
| 移除最后一张 | 集合清空、active/anchor 清空，预览为空，编辑与应用禁用 |
| Shift 点击 | 从 anchor 到目标（含端点）替换连续选区，目标成为 active，anchor 不变；无 anchor 则等同普通点击 |
| ⌘Shift 点击 | 将 anchor 至目标区间加入原集合，目标成为 active，anchor 不变 |
| ⌘A（Filmstrip 焦点） | 全选当前卷可用帧，保留 active；无 active 则取第一张 |

移除 anchor 后将其设为新的 active。排序变化按稳定 ID 保留选择，后续 Shift 范围以新顺序为准。缺失/不可用文件保留条目但不可加入选择；若已选文件在应用前丢失，应用失败且不修改任何帧。

## 复制参数

“复制参数”从 active 帧生成不可变快照，包含四个整数 Timing、四个 Contrast，以及快照格式版本、算法版本、固定 pivot 标识、来源帧 ID 与显示文件名。

不复制：片基选区、base、Linear Gain、自动偏移、矩阵、LUT、输入解释、输出 profile、选择状态、缩放与缓存。

无 active 时按钮禁用；多个选中项不影响来源。快照一旦复制，不随来源照片后续修改而变化。界面显示“已复制：文件名”。快照只在当前卷会话内保存在内存，不写系统剪贴板，不写项目；切换卷或退出时清空，避免无意跨卷应用。来源帧之后丢失不影响已经保存的快照值。

## 应用

按钮有快照且选择非空才启用。显示“应用到 N 张”，N 包含集合内全部目标；只选一张时应用到该张。点击时捕获快照和目标 ID 列表，不因异步渲染或后续选择改变目标。

1. 校验快照格式/算法兼容性、每个目标可用性与参数范围。
2. 整组覆盖目标帧的 Timing 和 Contrast，不加算、不乘算、不修改卷级校准。
3. 在一个事务中更新模型，一次性登记 undo，标记项目待保存并更新受影响缩略图。
4. 显示“已应用到 N 张”；不会改变当前选择或 active。

任一目标无效则整组失败，不产生部分应用。若所有目标原本已相同，则提示“所选照片参数已相同”，不增加无意义撤销记录。来源照片也在目标中时按同一规则覆盖。普通批量应用不弹确认对话框。

## 撤销与保存

一次应用对应一次 UndoManager 操作，每帧分别保存应用前参数；⌘Z 一次恢复全部，Redo 一次重新应用。手动滑块从按下到松开作为一组撤销，数值提交一次为一组。

重新采样或切换矩阵是一次卷级事务与撤销，恢复相关 base/gain/offset/matrix；保持帧级用户参数。撤销栈仅会话内有效，重开项目不恢复历史。复制不进入撤销栈。

应用后立即安排自动保存；保存失败保留内存参数和撤销能力，显示未保存状态与重试入口，不能错误提示“已保存”。保存策略见 [architecture.md](architecture.md)。

## Timing 快捷键

| 按键 | 操作 |
| --- | --- |
| Q / E | Red −1 / +1 CV |
| A / D | Green −1 / +1 CV |
| Z / C | Blue −1 / +1 CV |
| W / S | Master +1 / +1 CV |

仅编辑器或 Timing 面板处于编辑焦点、无文本输入焦点、无弹窗，且没有 Command/Control/Option 修饰时生效。Filmstrip 焦点不触发 Timing；⌘A、⌘C、⌘Z 和输入法不被截获。到达控件范围时停止，键盘重复可继续逐步调整。

## Filmstrip 与卷级状态

缩略图显示文件名、序号、当前/选中状态，以及帧级参数是否偏离默认值。校准状态来自整卷，可显示统一卷级标记；不能因为某帧 Timing 不为零就标记为未校准。

卷级校准改变会影响全卷预览与缓存，无需逐张“应用校准”。未校准时明确显示状态；用户可继续编辑和导出。首次打开只选中被打开的 TIFF；重开卷可恢复上次 active，明确打开另一张 TIFF 时以该文件为准。

## 0.2.0 新增操作

本节取代上文“当前没有独立手动旋转/翻转命令”的 0.1.0 边界。预览工具栏及“方向”菜单提供顺/逆时针 90°、当前显示方向水平/垂直翻转、重置。每次只改变 active 帧的方向，形成一次 Undo/Redo，重开恢复。组合与原始坐标见 [pipeline.md §10](pipeline.md#10-020-用户方向与原始坐标)。复制/应用仍然只含 Timing 和 Contrast，方向、输出设置不混入快照。

“1:1”/⌘1 使一个原片像素对应一个物理显示像素（Retina 使用 backing scale），居中读取当前可见原始区域；继续平移按需更新，读取中显示状态。适应窗口/双击/切帧/改方向复位视口。高倍缩放用原始区域覆盖低分辨率底图，像素不做精度降级；整图直方图保持独立。

Film Base 下方显示整图预览直方图，可选 RGB、R、G、B。调色面板滚动下方的输出设置可选四种 ICC 与无压缩/Deflate，无损 16-bit。选择输出设置立即保存，不影响显示预览。

导出菜单提供当前照片、选中集合、整卷三种入口。批量选择目录，当前照片可指定文件名。任务开始时固定目标及设置，此后可以调色、改变选择、Undo/Redo、旋转，不影响正在执行的任务；切换胶卷和退出须先完成或取消导出。进度显示照片及总体数量；结果逐张列出成功路径、失败原因、取消或未开始，用户可在 Finder 显示成功文件。单张失败继续其他帧，取消保留已完成并清理未完成临时文件。

缺失帧保留在 Filmstrip，右键“重新定位此照片”选择卷内 TIFF。手动重连保留稳定 ID、调色和方向；目标已被其他编辑帧占用时拒绝合并，原路径仍可读时拒绝误重连。片基来源重连后提示复核。输出面板可主动清理可再生缩略图缓存。
