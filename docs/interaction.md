# 编辑交互

当前版本0.3.69。本文规定当前有效的界面与编辑语义；数值见[pipeline.md](pipeline.md)，保存与模块见[architecture.md](architecture.md)。面向使用者的简短说明见[使用指南](user-guide.md)。

## 布局

主预览在左、调色面板在右，Filmstrip 位于底部。调色面板按编号依次显示：01 矩阵矫正（上 CMOS 矩阵、下密度矩阵）、02 Film Base 对齐、03 Color Timing、04 RGB Contrast、05 Cineon Log LUT。Film Base 对齐与矩阵矫正为独立分组，均作用于整卷；片基来源复核提醒留在对齐分组。输出选项在导出对话框中显示。主预览支持缩放、平移、片基矩形选区、阶段切换与中性点吸管。

双指滑动按 macOS 滚动事件的方向平移照片，遵循系统“自然滚动”设置，不额外反转水平或垂直位移。

预览视口由页面剩余空间决定；缩放和平移只改变视口内的图像变换，不参与页面尺寸计算。SwiftUI 容器、AppKit Canvas 及绘图上下文都裁剪到此边界，图像与选区不得覆盖工具栏、右侧面板或 Filmstrip。片基选区同时受图像与视口交集约束。

鼠标按下、滚轮、捏合和取样只响应视口内位置；拖出时暂停平移/框选，重入不累计窗外平移量，窗外松开取消提交。窗口改变尺寸时取消进行中的拖动，避免混用两套坐标。取样仍按完整 imageRect 逆映射到 orientation 校正后的原始尺寸，不用可见裁剪矩形拉伸映射。“适应窗口”、双击和切帧统一清除平移与临时选区并恢复居中 fit。TIFF 方向校正在导入阶段完成，用户追加方向见预览工具栏中的方向操作。

面板始终编辑当前主预览帧 `activeFrameID`，即使选中多张，拖动控件也只修改当前帧。批量修改通过明确的“应用”按钮进行。卷名显示在主工具栏，Filmstrip 突出当前帧；调色面板不再重复“当前照片”或“正在编辑”文字。

## 当前帧、选择集合与锚点

维护三个独立状态：`activeFrameID`、`selectedFrameIDs`、`selectionAnchorID`，均使用稳定帧 ID。非空选择中 active 必须是集合成员。当前帧突出边框，其他选中帧使用选择背景；两种状态不能只有不可辨认的细微色差。

| 操作 | 行为 |
| --- | --- |
| 普通点击 | 集合替换为该帧，该帧成为 active 和 anchor |
| ⌘ 点击未选中帧 | 加入目标集合，保持 active 和 anchor |
| ⌘ 点击已选中非当前帧 | 从目标集合移除，保持 active 和 anchor |
| ⌘ 点击当前帧 | 不改变选择；active 始终保持选中 |
| Shift 点击 | 从普通点击确定的 anchor 到目标（含端点）替换连续目标集合，保持 active 和 anchor，并确保 active 仍在集合中；无 anchor 则等同普通点击 |
| ⌘Shift 点击 | 将 anchor 至目标区间加入原集合，保持 active 和 anchor |
| ⌘A（无文本输入焦点） | 全选当前卷可用帧，保留 active；无 active 则取第一张 |

⌘/Shift/⌘Shift 只修改批量目标，不切换主预览，不取消裁剪草稿，也不复位缩放或平移；普通点击才切换 active 并重新确定 anchor。没有 active 的初始状态以首个有效点击建立 active 和 anchor。排序变化按稳定 ID 保留选择，后续 Shift 范围以新顺序为准；外部源变化导致 active 不再可用时才按可用集合修复选择。缺失/不可用文件保留条目但不可加入选择；若已选文件在应用前丢失，应用失败且不修改任何帧。

## 复制与同步

⌘C复制当前照片的Timing、Contrast和Cineon Log LUT为不可变快照；之后修改来源不改变该快照。⌘V覆盖全部所选目标，不累加。快照仅当前卷会话有效，切卷或退出清空；来源丢失不使已复制值失效。方向、裁剪和卷级校准不进入调色快照。

Filmstrip上方“同步…”在多选时启用，从当前照片已提交设置覆盖其余所选照片，目标数排除当前帧。提供RGB Timing、RGB Contrast、Cineon Log LUT、裁剪四项，每次打开全部不勾选，至少选择一项才可应用。切换当前帧或选择集合关闭浮层。裁剪需先完成再同步；同步保留目标各自方向和未勾选内容。

全体目标先校验，失败整组不变；成功一次事务、一次撤销，保存并更新目标缩略图。完全相同的结果不增加撤销。取消或关闭浮层不修改项目，来源帧与选择集合保持。

## 撤销与保存

单次滑杆拖动、数值提交、连续长按或批量命令分别组成一组撤销。矩阵应用与片基重新对齐共同提交和撤销，逐帧Timing/Contrast保持。复制本身不产生撤销，重开项目不恢复撤销历史。

普通调参防抖保存，操作结束和批量命令安排立即保存；保存失败保留内存参数、dirty与撤销，显示错误及重试入口。切卷、返回主页和退出先检查保存；主窗口关闭在保存成功后退出，导出进行中或保存失败时保留窗口。关闭辅助窗口不退出。持久化规则见[architecture.md](architecture.md)。


## 调色快捷键

下表为RGB Timing模式；简易模式的路由见下一节。

| 按键 | 操作 |
| --- | --- |
| Q / E | Red −1 / +1 CV |
| A / D | Green −1 / +1 CV |
| Z / C | Blue −1 / +1 CV |
| W / S | Master +1 / −1 CV |
| [ / ]（【 / 】） | 当前照片左旋转 / 右旋转 90° |
| ⌘F | 当前画面水平翻转 |
| ← / → | 上一张 / 下一张可用照片 |
| I | 开启 / 取消中性点吸管；长按不反复切换 |

窗口内无文本输入焦点、无弹窗、未进入裁剪且没有 Command/Control 修饰时生效。点击 Filmstrip 先提交数值输入并结束文本焦点，随后可以直接调色；不再存在 Filmstrip 专属调色焦点模式。无 Option 调 Timing，有 Option 调对应 Contrast。⌘A 在无文本焦点时全选照片，在文本内保留全选文字；⌘C/⌘V 在无文本焦点时复制/应用参数，在文本内保留文字复制/粘贴；⌘Z 和文本输入法不被调色字母键截获。单击每次 1 CV，Shift + 快捷键单击每次 10 CV。按住约 0.4 秒后由应用计时，以固定 25 CV/秒连续调节，不渐进加速，Shift 不放大连续速率；不依赖 macOS 键盘重复设置。松手立即停止；换键重新计时，切帧、失焦或弹窗时终止。一次按住到松开对应一次撤销/重做，到达控件范围即停止变化且不追加空撤销。滑杆、输入框及快捷键共享 [pipeline.md §7](pipeline.md#7-timing-与-rgb-contrast) 的范围。

## 简易 / RGB Timing

Timing标题行提供“简易 / RGB”分段切换，吸管仍在最右侧。首次默认简易，本机偏好记住选择；切图、切卷、重启保持，复制/同步/撤销不改变模式。切换停止在途长按，参数和画面不变，不单独产生撤销。

简易模式显示曝光、色温、色调及可编辑数值；色温左冷右暖、色调左绿右洋红，悬停和辅助功能提供方向/按键。三条滑杆后保留一行空白，Contrast位置与四条RGB模式相同。拖动一次为一组撤销，双击复位遵守pipeline.md的整数格点/范围约束。

全部调色滑杆支持双击复位当前一项：简易曝光/色温/色调与RGB Timing的Master/R/G/B目标为0，Contrast的Master/R/G/B恢复无调整值1.00。仅滑杆区域响应，数值输入框保持原生编辑行为；参数、数值与滑块位置同步刷新，沿用调参撤销流程。裁剪角度滑杆继续双击归零。

仅Timing快捷键随模式变化：简易W/S曝光增加/减少，Q/E偏冷/偏暖，A/D偏绿/偏洋红，Z/C无作用；RGB模式保留原路由。简易单击1、Shift单击10，0.4秒后每秒25个轴单位，无Shift长按加速。所有Option反差快捷键在两种模式均保持原含义、步长、长按速率和可用条件，包括Option+Z/C。文本、弹窗、裁剪及失焦保护沿用原有规则。帮助窗口分别列出两种Timing模式，并明确反差通用。

简易模式数值显示为四舍五入的整数，底层坐标与继承分数余量保留；仅查看和切换模式不修改参数。LUT逐帧可选Fujifilm 3513DI或Kodak 2383，默认Kodak 2383；顶部重置同时恢复Timing、Contrast和LUT。


## Filmstrip 与卷级状态

Filmstrip 可用帧的右键菜单提供“水平翻转x张底片”“垂直翻转x张底片”“顺时针旋转x张底片”“逆时针旋转x张底片”，x 为当前选中集合数量（包含当前帧）。右键不改变选择；操作作用于所选集合，每帧基于自己的当前画面翻转或旋转 90°，保留原片裁剪与调色。整组校验、一次撤销/重做、自动保存并刷新受影响缩略图；缺失目标则全部不改。裁剪编辑、胶卷加载或无选择时禁用。预览工具栏与快捷键仍只改变当前帧。

缩略图显示文件名、序号、当前/选中状态；不再显示帧级参数偏离默认值的黄点。校准状态来自整卷，可显示统一卷级标记；不能因为某帧 Timing 不为零就标记为未校准。

卷级校准改变会影响全卷预览与缓存，无需逐张“应用校准”。未校准时用户可继续编辑和导出；调色面板不再显示常规校准数值与说明，只有片基来源变化需复核时显示操作提醒。新卷选择首个可用帧；重开卷恢复上次当前帧。

## 双矩阵管理

“01 矩阵矫正 · 整卷”标题右侧提供“管理…”，点击浮层选择 CMOS 矩阵或密度矩阵，再打开对应管理弹窗。主面板上下两行分别为 CMOS、密度矩阵，每行左侧标签、右侧选择器。新建胶卷默认 CMOS 为 Sony A7C II、密度为 LED Light Source；两侧仍可选 Identity，已有胶卷读取保存的选择。内置项带锁，只读、可复制，不能编辑或删除。

管理弹窗左侧为内置和本机矩阵列表，支持新增、复制、删除；右侧名称与按输入列/输出行标注的 3×3 系数。CMOS 新增通过选择三张TIFF／ARW，后台自动识别、求解，展示 R/G/B 对应文件及系数，再命名保存；CMOS 系数只读，可重新选三张TIFF／ARW 计算、重命名、复制。密度矩阵允许逐项输入小数、负值及粘贴九个按行排列数值。非法或不足九项不能保存。

“保存到电脑”只更新本机矩阵库；“保存并应用到本卷”另以一次可撤销的卷事务应用新快照。应用到已校准卷会自动重新对齐片基，与矩阵合为一次撤销；保存到电脑不影响卷校准。等待期间保留原画面，失败提示并保留原矩阵和校准。当前卷使用的已删除或旧版预设显示为“本卷快照”，可继续渲染和保存；重新选择库中的版本才更新。改库不联动其他卷。关闭弹窗丢弃尚未保存的草稿，取消在途标定。弹窗、浮层和文本输入期间不触发调色快捷键。

导出统一使用Final，不提供独立CMOS校正输出。

## 最近胶卷

启动保持欢迎页，打开按钮下显示最近成功打开的胶卷：文件夹名称、路径、最近打开日期；单击打开并沿用上次 active 恢复规则。按打开时间倒序，同一规范化文件夹去重，最多20条，超过6行滚动。文件菜单提供同源的“最近打开的胶卷”。不读取原片生成封面。

悬停行尾×或右键“从最近记录中移除”仅删除本机历史，不改变原片与旁存项目，无确认弹窗；最后一次移除提供6秒撤销入口。再次打开重新记录。不可用位置保留并标注；点击可连接磁盘后重试或选取新位置，重新定位要求原项目UUID一致，成功才替换旧路径。导出期间禁用打开，切卷沿用保存失败保护。

## 整卷加载页面

新卷和旧卷使用同一“正在加载…”页面，显示进度条及“已完成 / 总数”（待检查的可用RAW张数），提供“取消加载”。加载期间不展示编辑控件、Filmstrip或主预览，不允许编辑/导出。所有代理成功就绪后进入编辑，才启动缩略图任务。有效缓存计入完成，自动清理后缺失的缓存先补齐；不以是否首次导入决定行为。失败显示“加载未完成”、失败文件及原因，提供“重试”和“返回主页”，不进入半就绪编辑器。

## 预览工具栏

预览阶段入口固定命名“管线预览”，旁边显示当前选项；仅提供“线性 / 密度 / 输出”，分别绑定 L2 / D3 / Final，默认输出。菜单以勾选显示当前项，不暴露其他内部阶段；“线性”是显示名称，TIFF 与 RAW 通用。阶段计算与显示转换继续遵守 pipeline.md。

裁剪/方向、管线预览、缩放分三组，以留白及淡竖线分隔。方向使用四个图标按钮，管线预览使用原生菜单及单向下箭头；共用26pt内容高度、12pt字的外观组件，颜色跟随主题，悬停淡底。裁剪保留图标及文字，香槟金仅表示当前工具/缩放选中状态。

缩放合为“适应 / 100%”分段外观；无论 TIFF 或 RAW 代理，按钮文字始终为“100%”。状态由真实视口回报：居中且适应比例时选中适应，一个原片像素对应一个物理像素时选中1:1，其余手动缩放不选中任何段。裁剪时缩放禁用；快捷键、双击复位、方向操作与裁剪提交语义保持。

TIFF的100%读取原始区域，RAW的100%放大代理，悬停提示全尺寸仅用于导出；日常操作不额外去马赛克。切帧先显示匹配缓存或Final缩略图占位，再替换正式预览；占位时禁用精确取样、裁剪和1:1操作。


## 裁剪与同步

预览工具栏在方向图标左侧提供“裁剪”，R 进入。裁剪栏为单行：比例菜单、横竖切换、角度减/滑杆/加、两位小数角度输入、重置、取消与完成。比例提供自由、3:2、4:3、1:1、7:6；滑杆范围 ±10°，按钮每次 0.1°，输入精确到 0.01°，双击滑杆归零。栏内不显示输出尺寸或常驻说明，名称与帮助通过悬停和辅助功能保留。没有画线自动拉直工具。重置裁剪显示“全图”，属于草稿，完成时才清除帧裁剪。

编辑时展示全图，框外暗色遮罩仅覆盖旋转后的照片范围，不压暗照片外的画布底色；保留网格、四角四边把手；框内拖动移动，固定比例时边角拖动保持比例，自由比例时可独立改变宽高。照片围绕全图中心旋转，框始终水平；显示角度与横竖按当前照片方向呈现，保存时转换为原片坐标。约束与自动收边由 pipeline.md §14 定义。Enter/完成只修改当前帧；Esc/取消恢复进入前裁剪，整次提交一次 Undo。R、Enter、Esc 仅无文本输入/弹窗时由编辑器处理；角度输入 Enter 先提交数值。编辑中不触发方向变换、1:1 或导出；无修饰键时 W/S/A/D 分别将裁剪框上/下/左/右移动约 0.3% 画面尺寸，系统按键重复可连续移动。Filmstrip 普通点击或左右方向键切换当前帧时保持裁剪模式，先提交上一张当前裁剪（含重置全图），登记一次撤销、刷新缩略图并立即自动保存，再按新照片自己的已保存裁剪初始化草稿（无裁剪时沿用进入裁剪的默认值）。加载期间禁用裁剪编辑和提交，⌘/Shift/⌘Shift 扩选保持当前照片和草稿。按住调色键的动作在进入裁剪时结束。

裁剪栏只编辑当前照片，完成后再使用 Filmstrip 上方统一同步入口。裁剪编辑期间同步禁用，提示先完成裁剪。同步的原片范围、细角度与方向保留规则见“复制与同步”及pipeline.md §14。

草稿在完成或切换照片时提交，此前不写项目或导出快照。未加载完成的照片在快速切图时不提交空草稿；点击当前照片或到达首尾不提交。Esc/取消仅丢弃当前照片草稿，已经切走的照片裁剪保持。保存失败沿用顶部未保存提示和重试，保留内存裁剪与撤销。完成后自动保存，预览按裁剪预览开关恢复显示；Filmstrip与直方图使用已提交裁剪，导出遵循应用裁剪设置。片基取样的全图恢复规则见 pipeline.md §14。复制调色包含Timing、Contrast和LUT，不包含裁剪。

裁剪模式Q/E每次调整角度−0.1°／+0.1°；普通预览和裁剪复用同一画布，进入、完成或取消时保留旧画面直到新预览就绪。


## 裁剪预览

“管线预览”左侧提供“裁剪预览”复选框，默认勾选。取消勾选显示完整画面并隐藏裁剪微调角度，保留独立旋转/翻转与当前调色；直方图仍按已保存裁剪范围统计。开关是会话状态，切图和切卷保持，重启默认勾选，不写胶卷或导出偏好。裁剪编辑仍显示完整画面和草稿框，完成/取消后恢复开关指定的预览。切换时复位视口适应画面；100%查看、吸管与悬停取样按当前显示几何映射。缩略图、自动分析、调色参数与导出不受开关影响。

## 自动裁剪与自由比例

裁剪比例菜单提供“自由”；切换时保持当前框，边和角可独立改变宽高，自由时禁用横竖比例交换。未裁照片初次进入裁剪以全图自由比例开始；重置后的角度控件与Q/E也使用全图自由比例。固定比例、Q/E和其他快捷键保持。

顶部在“重置调色”左侧依次显示“自动裁剪”“色罩分析”，移除预览工具栏的自动裁剪及TIMING标题行的魔棒入口。点击后打开设置对话框：画幅比例默认3:2，提供3:2、4:3、1:1、5:4、7:6、2:1、3:1与自定义；无自动识别比例选项。自定义输入宽、高正数（可含小数），“交换宽高”用于竖幅；有效比值范围1:10～10:1，非法输入显示错误并禁用开始。比例按原片坐标解释，选项仅用于本次运行、不记入项目；开始后锁定。“保留已裁剪”默认不勾选；勾选时保护手动、旧版和上次自动生成的全部现有裁剪，包括手动重置的全图；取消勾选则重算所有非缺失照片。“每边内收”使用下拉框，仅提供0%、1%、2%、3%、4%、5%六档，默认1%。对话框不显示说明小字，只保留选项、操作按钮和运行进度。开始后选项锁定，对话框保持打开并原位显示两遍分析进度和“取消分析”；分析运行时不能关闭对话框。整批结果一次提交、一次撤销，取消或失败不提交部分结果。

完成后，有待检查照片时自动关闭对话框、进入第一张待检查照片的裁剪模式，并默认“仅看待检查”；没有待检查时直接结束。人工检查的“待检查 N 张”“仅看待检查”和“确认并下一张”均显示在裁剪栏，待检查为0时全部隐藏；Filmstrip标题行不显示进度、状态或检查按钮。筛选同步作用于缩略图和左右键，原卷编号不变。回车（含数字键盘 Enter）与“确认并下一张”按钮执行同一操作，长按不重复确认；角度输入框中仍先提交数值。确认保存当前草稿、清除标记并前往下一张；最后一张确认后结束检查、恢复完整Filmstrip。关闭筛选可浏览整卷，切图仍自动保存裁剪。

待检查状态不在Filmstrip添加专用标记；人工检查期间由裁剪栏数量和“仅看待检查”筛选表达。检查标记与裁剪一起保存/撤销；筛选不写入胶卷。

## 直方图与取样

直方图位于预览右上角，Density／Final独立于画面阶段，默认Final，固定RGB叠加。收起状态本机记忆；直方图统计整张裁后预览，不随平移或100%局部变化。72%不透明度浮层，绘图区有完整外框；横轴、纵轴及取样算法见pipeline.md。

Color Timing 标题右侧提供中性点吸管。点击或按 I 启用，预览内指针变吸管，尖端为取样点，点一次完成并退出；Esc/I/再次点击按钮取消。I 沿用窗口快捷键的文本输入、弹窗与失焦保护，长按不反复切换。片基框选状态在预览内显示十字指针；工具切换、取样完成和取消立即更新鼠标形状，无需移动。移出预览后由所在控件使用正常指针。片基框选与裁剪互斥，正式预览未准备好时禁用精确取样。采样范围为原片长边0.8%的方形，网格取整与边缘截短见pipeline.md §15；取样以邻域的 Final 中位数为中性目标，尽量保持最终亮度；目标和数值容差以 pipeline.md §15 为准。帮助文字标明 Final 中性，不随当前诊断阶段改变目标。只改变当前帧 RGB Timing，整次操作一次撤销并沿用保存、缩略图与复制语义。取样等待中切帧、调参、切阶段、改校准/几何或取消时丢弃结果；无效取样、无法收敛或整数精度不足等求解失败时直接结束取样，不弹窗、不重新载入照片，已有参数及撤销记录保留；文件读取或源变化错误仍沿用原错误处理。求解在后台进行，等待期间取消或继续调色会丢弃结果。

普通预览默认箭头，实际按住拖动画布时为闭合抓手，松开恢复箭头；吸管、片基十字和裁剪边缘指针保持。悬停照片时，直方图显示RGB三条半透明细线（45%不透明度，无底部三角或黑色描边；从底部延伸至各自通道在该横坐标的已绘制曲线高度，按相邻点插值），横坐标按直方图自身Density/Final阶段的邻域中位数定位；不增加常驻读数或照片取样框。取样契约见pipeline.md。照片外、直方图面板上、拖动期间、片基或裁剪模式和占位预览不显示；松开或回到照片后恢复。超过横轴范围的值显示在对应端点。

每条悬停标记线的曲线交点增加对应RGB颜色的实心圆点（直径5点，0.75点半透明浅色描边），帮助辨认位置；保留半透明短线，无底部三角。

## 整卷自动调色

顶部“色罩分析”调用整卷自动调色。需有效片基校准、无需复核且当前矩阵与校准快照一致；裁剪、片基框选、自动裁剪、导出或加载期间不可调用。忽略多选范围，分析整卷可用帧的裁后画面。

点击先显示“色罩分析”确认弹窗，提示“将开始整卷色罩分析，请确认已完成有效画幅裁剪和片基框选”，提供“取消”和“开始分析”；只有点击“开始分析”才启动整卷分析，取消不启动。分析期间同一对话框仅显示标题、进度和“取消分析”。完成后标题为“分析完成”，显示“整卷 RGB Timing”及带正负号的R/G/B整数结果，下方为“保留已调色”（每次默认不勾选），按钮为取消和应用到整卷。勾选仅保护Timing或Contrast非默认值的照片，LUT/裁剪/方向变化不算已调色。该选项只影响应用范围，不影响整卷统计。分析统一使用卷内第一张照片所选LUT。应用统一RGB、Master=0、四项Contrast=1，并将所有应用目标的LUT覆盖为分析时第一张照片的LUT，保留裁剪和方向；勾选“保留已调色”时，被保护照片的全部调色及LUT保持；整卷一次撤销，之后可正常精调。取消无参数写入。分析失败在原对话框显示原因和取消，不显示应用按钮。

## 导出

当前照片、所选照片和整卷入口直接确定导出目标。独立设置窗口只显示目的地、文件名前缀、格式、色彩空间、ZIP 压缩和应用裁剪；点击目的地“选择…”才打开系统目录选择器，随后点击“导出”直接开始。未选目录、目录不可用或前缀非法时禁用导出。取消不保存草稿；点击导出时每卷保存目的地和输出选项。前缀默认随卷名，名称中的非法文件名字符在前缀中替换为下划线；手动改前缀后不再跟随卷名。ZIP 压缩以复选框呈现，仅在 TIFF 格式时显示，取消即无压缩。应用裁剪对 TIFF/JPG 均显示；关闭时导出完整画面并忽略裁剪微调角度，保留独立旋转/翻转，不改照片裁剪与预览。两项初始默认勾选，随后按卷记忆，旧项目缺少应用裁剪字段时按启用读取。自动追加胶卷完整顺序的一起始编号，至少两位，例如 `假日-02.tiff`；单独导出第二张仍为 02。重名时询问覆盖、自动重命名或取消，卷内原片始终禁止覆盖。

菜单顺序和名称为 sRGB IEC61966-2.1、Display P3、Adobe RGB (1998)、ProPhoto RGB、Rec. 2020。新卷默认 Display P3。读取旧 p3 或未知输出空间时，内存设置自动回退 Display P3 并更新对应 ICC 指纹，下次正常保存写回；有效选项保持。读取本身不直接写盘。转换定义见 pipeline.md §11。

顶部导出菜单显示“导出”；格式下拉提供16-bit TIFF和8-bit JPG，初始TIFF，确认导出才保存选择，取消不写入。两种格式均提供现有五项输出ICC。JPG固定最高编码质量，隐藏ZIP压缩复选框；切回TIFF恢复已选压缩状态，初始默认勾选ZIP。输出扩展名随格式为.tiff或.jpg。

导出冻结提交时的目标与参数，允许继续调色；运行中不能切卷，取消保留完成文件，摘要逐张列出状态。裁剪中的导出入口禁用。


## 管理缓存

File → 管理缓存… 在主页和编辑中均可打开独立窗口。显示“缓存大小 2.5/8.0 GB”（实际用量/已保存上限，十进制GB），打开期间每2秒刷新。缓存上限输入GB，按“应用”或Enter保存；允许0.1至100000的有限数值，非法输入提示且保持原设置。删除期限下拉提供3天、7天、30天、永不，选择立即保存。本机记忆，默认8GB/30天；期限按最后使用时间，永不只关闭按天删除，容量淘汰仍生效。容量设置和期限均作用于所有系统缩略图与RAW持久缓存，超限先删最久未使用项。应用退出时不运行清理，下次启动补做；后台清理可能等待正在读取/导出的RAW完成。窗口不显示清理策略说明小字，不添加项目参数或撤销操作。


主页“打开底片文件夹”右侧增加带硬盘图标的“管理缓存”次级按钮；打开文件夹保留金色主按钮，缓存使用标准边框按钮。两个入口复用同一个独立缓存窗口，空历史与最近胶卷状态均可用。移除缓存窗口底部整段清理策略说明。

## 深浅外观

顶部 macOS 菜单栏“外观”提供“浅色 / 深色”并标记当前选择，即时应用到主窗口、辅助窗口及原生对话框。本机记忆，重启保持；首次使用沿用深色。照片画布遵循下方语义色规范；主页背景随主题变化。工具栏、调色区、直方图与缩略图选中状态适配主题，外观不写入胶卷项目。
