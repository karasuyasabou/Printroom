# 整卷自动裁切实验（2026-09-16）

独立 Python 研究脚本，不接入 Printroom，不修改原片、`.printroom.json` 或正式应用。输入固定为本机 `2026-09-01-1/RAW` 的36张现成线性代理；先按文件修订对应缓存，再校验代理SHA-256。所有图像与结果在被忽略的 `scratch/autocrop-study/`。

## 方法

整卷一个固定宽高，不分组。将代理降采样至800×533，仅在分析副本计算负对数灰度；搜索外围朝向画面内的密度上升边，排除方向相反的外侧夹具边。先搜索±3°，从四边支持充分的30张估计宽高中位数，再逐帧拟合中心与角度，宽高固定。三条边有支持即可自动通过，第四边可由整卷尺寸补全。阈值为本轮工程试验值，支持度不代表正确概率。

最初纯宽边缘支持目标在合成强边缘上有角度平台（一个案例误差0.4°）；加入窄范围梯度峰值项后，5个已知角度/位置的合成案例全部满足中心误差<2代理像素、角度误差<0.12°。最终最大中心误差0.421代理像素，角度误差0.011°。合成结果不代表真实照片精度。

## 最终实测

- 36张，32张算法自动通过，4张待检查（DSC07098、07099、07100、07104）。
- 估计固定画幅1427.5×958.77代理像素；输入代理1600×1066。
- 模板种子宽/高MAD分别为1.5/1.0代理像素。
- 从已缓存代理读取、校验和分析共约5.6秒，不含首次RAW解码和报告图片生成。
- 检查了36张裁框总览，并放大抽查普通帧及低支持帧。未建立逐帧人工标注真值，32/36是分流比例，不是已验证正确率。
- 真实画幅边缘存在不规则轮廓和圆角，贴边矩形可能留下细小片基。报告提供每边再内收6代理像素（约26原片像素）的独立对照，不用于改变检测置信度。
- 本卷未见明显严重漏光片头/片尾，不能据此宣称那类异常已验证。待检查帧主要为暗部接近片基、边界低对比。
- 报告负片仅按通道百分位归一并调整显示亮度，不是正式Printroom色彩输出；未读取或借用手工裁切作为检测输入。

## 复现

在项目根目录建立隔离环境并安装 `requirements.txt`，然后：

```sh
scratch/autocrop-study/.venv/bin/python scripts/autocrop-study/inputs.py
scratch/autocrop-study/.venv/bin/python scripts/autocrop-study/run.py
scratch/autocrop-study/.venv/bin/python scripts/autocrop-study/check_geometry.py
scratch/autocrop-study/.venv/bin/python scripts/autocrop-study/report.py
```

查看 `scratch/autocrop-study/index.html`：支持整卷/待检查筛选、原图/裁框/裁后/内收对照、单张放大和左右键。`results.json`记录每张中心、角度、四边支持度和代理坐标裁框，`synthetic-check.json`记录合成几何检查。

## 第二卷：2026-09-01-2

同一算法与阈值运行40张已缓存代理，约6.35秒；固定画幅1418×947.77代理像素，37张种子。原算法39张自动通过、1张待检查（DSC07128）。查看整卷裁框，并放大检查DSC07115、07128、07153、07154。

**发现置信度漏报：** DSC07115明显漏光，左侧边界不可靠却被自动通过。三边证据与尺寸补全能产生合理大小的矩形，但不能证明异常帧可跳过人工。末尾DSC07153/07154的异常边界也值得人工复核，不把它们的高边缘得分视为验收。39/40不是成功率。本轮不调整算法或阈值，报告保留原始绿色状态，并单独附视觉复核说明。

现有算法缺少边框外片基是否仍像本卷正常片基、边缘局部异常等证据；未来应将它们用于异常分流，不需要普遍收紧正常照片。第二卷结果位于 `scratch/autocrop-study/roll-2/`，不覆盖第一卷。

指定另一卷时为各命令设置 `AUTOCROP_SRC`（RAW文件夹绝对路径）和 `AUTOCROP_OUT`（独立输出目录）即可，检测算法保持原样。报告网格已支持非36张胶卷。
